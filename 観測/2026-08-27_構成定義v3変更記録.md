`2026-08-26-成立規定-2`

`2026-08-27-成立規定-3`

## 変更理由

MINIDORA GPQA Diamond 198問の逆算監査により、質問・候補・外部Dataの入口被覆を改善しても成立差形成が改善しないことを確認した。

主要観測:

- 質問関係: 198 / 198
- 正式候補射影: 741 / 792
- 参照資料取得: 2708
- Data compile failure: 0
- 一意成立差なし: 91問
- 参照寄与なし: 22問
- 回答: 84問
- 正解: 17問
- 誤答: 67問
- checkpoint: 591
- checkpoint再活性: 0
- 大域再照合: 0
- 候補横断更新: 0
- 専門作用起動: 0
- working relation関連: 0

この結果だけで規定を変更せず、既存のK3 D4構文化、K3以外10モデル横断構文化、LLM能力保存作用則v1を再照合したところ、状態保持・再作用・再参照・再結合・終端遅延・形成分離が既に抽出済みだった。

したがって原因を「新しい作用の発明」ではなく、**v2正本から下流再構成への圧縮時に構成作用が落ちたこと**として扱い、既存構文化済み情報を正本へ戻した。

## 主な変更

1. `模型側関係`を単発の静的関係から、保持差へ再作用・再参照・再結合して終端成立差へ到達する作用連鎖へ拡張。
2. `状態保持 / 再作用 / 再参照 / 再結合 / 終端遅延`を基底語彙へ追加。
3. `作用機構`と`形成済み関係`を分離。
4. `形成履歴`と`形成済み関係`の混線を解消。
5. 内部観測可能模型向けに構成作用監査を追加。
6. 下流逆算監査を、独立構文化との一致確認を条件に再開放経路へ追加。
7. v2正本内の`06_再開放.md`の版表示不整合も修正対象へ含めた。

## 非変更

- 言語模型性成立条件はv2の5区別を維持する。
- Transformer等の方式名を普遍条件にしない。
- 確率分布を普遍条件にしない。
- 生成運用性を模型成立から分離する。
- 規模三面を維持する。
- 下流MINIDORAを成立証人にしない。
- benchmark点数を正本へ直接逆輸入しない。

## r2 独立関係監査による追補

前回候補を前提にせず、既存構文化から関係を再列挙した結果、次を追加・修正した。

- 状態分離を追加。
- 状態保持を「後段利用可能性」まで含む語義へ強化。
- 状態更新を追加。
- 未確定差の共存を終端遅延から独立。
- 寄与調整と確定境界を分離。
- 再作用閉包を追加。
- 再参照を普遍必須物理形から外し、段階輸送との複数成立形へ修正。
- 作用範囲、作用分岐・合流を構成観測軸として追加。ただし普遍物理形にはしない。
- `規定/03_規模記述.md`を更新対象へ追加し、作用域を既存三面の補助記述へ統合。
- 模型側関係と、その関係を実現する構成連鎖の語義混線を解消。

## r3 独立監査による二層化

- 言語模型性成立条件をv2の5区別へ戻した。
- 高粒度作用群を `構成再現条件` として独立。
- 閉鎖模型の内部未観測をLLM不成立へ誤変換しない。
- `言語模型適合` と `構成再現適合` を別監査軸へ分離。
- MINIDORAの逆算監査は主に構成再現条件の更新根拠として扱う。
- `意味同一性`を構成再現条件へ明示し、言語関係同一性の語義を段階横断追跡まで拡張。
- 形成済み関係を「分離」だけでなく「現在模型物内で保持される関係差・適用条件・優先差の再現」まで強化。
- 大規模言語模型の短縮定義をv2最小条件へ戻し、構成再現の短縮定義を別掲。
