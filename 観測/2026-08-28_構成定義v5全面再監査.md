## 2. 旧仕様系列から分かったこと

### 2.1 旧 LLM_func は狭すぎた

旧統合不可約仕様は `LLM_func := f : Text × Context → Text` を中心に置き、F1 content-addressable retrieval、F2 parametric competence storage、F3 sufficient serial depthを成立条件候補としていた。

これは当時のdecoder型LLMには有効な解析だったが、現在の横断対象には狭い。

- BERTはmasked bidirectional representation / masked token predictionを持ち、通常のText→Text生成関数だけでは捉えにくい。
- LLaDA / iLLaDAはautoregressive serial generationを必須としない。
- RWKVはTransformer物理形を必須としない。
- REALM / RETROは知識をparametric storageだけへ閉じず、retrievalを模型作用へ統合する。

従って旧F1/F2/F3を普遍的な「LLMをLLMたらしめる条件」へ戻すことはできない。

### 2.2 LLM-first conformance protocolはLLM存在論の根拠ではない

`llm_first_conformance_protocol_v4.pdf` は、LLMをVerifier / execution engineとして用いる適合・監査protocolである。

これは監査可能性・停止性・役割分離には有用だが、**LLMそのものの成立条件を定義する資料ではない**。ここからLLM構成条件を逆算しない。

## 3. v4言語模型性五条件の誤り

v4五条件:

1. 独立対象
2. 文脈依存関係
3. 関係再利用
4. 言語対応
5. 局所対応

### 3.1 模型内在条件と監査条件が混在していた

`独立対象` は、候補模型を見てから対象を後付けしないための**監査方法**であり、模型内部の性質ではない。

`局所対応` も、現在証拠から成立主張を採用してよいという**認識状態**であり、模型を構成する性質ではない。

`言語対応` は模型interface・token mapping等に関係し得るが、規定上は外部から模型内部差を追跡する監査境界としても使っていた。

したがって「五条件」という一表に置いた時点で階層混線していた。

### 3.2 固定classifierを五条件だけでは十分排除できない

v4本文は別節で固定ラベル分類を除外していたが、五条件そのものだけを見ると、対象言語関係を恣意的に設定すれば分類器へも対応関係を作れてしまう。

つまり非言語模型との境界が成立条件本体ではなく後段除外規則へ逃げていた。

### 3.3 修正

模型内在条件を次の四条件へ再構成した。

1. 言語状態域
2. 条件付き言語差形成
3. 構成再利用
4. 言語状態接続

旧 `独立対象 / 言語対応 / 局所対応` は識別監査へ移した。

## 4. v4構成再現七条件の誤り

v3/v4は高能力LLM横断観測から、状態保持・未確定差共存・寄与調整・再作用・再結合等を抽出した。この観測自体は維持できる。

誤りは、**観測された共通作用群を固定七条件として「構成再現一般」へ昇格したこと**にある。

### 4.1 元模型相対性が不足していた

構成再現とは、本来「何の模型の、どの構成を再現するか」に依存する。

Llamaのglobal causal attention、RWKVのrecurrent state、LLaDAのmasked diffusion、REALMのretrievalは構成が異なる。

高能力群に共通して見える作用を抽象化することは有用だが、その抽象語すべてを、全元模型・全能力の構成再現へ同一に要求する根拠にはならない。

### 4.2 因果不変量と共存特徴を分けていなかった

ある部品・状態・経路が「存在する」ことと、その能力成立へ因果的に必要であることは別である。

v5では構成再現を、元模型相対の `構成再現対象プロファイル` と、介入・除去・比較等で支持された `構成不変量` へ変更する。

### 4.3 七条件の処置

七条件は削除せず、**構成観測軸**へ降格する。

これによりK3等から得た重要な状態保持・再作用知見を捨てず、普遍化だけを解除する。

## 5. 機能再現と構成再現の混線

これはMINIDORAに直接重要である。

非ニューラル模型が既存ニューラルLLMと同じ言語模型機能を別原理で成立させることが目的なら、第一に必要なのは **機能再現** である。

元LLMの内部状態保持・Attention・residual相当を忠実に再現する必要はない。

v3/v4構成再現七条件をMINIDORAの普遍設計要件として読むと、**代替原理を作るための模型へ、元ニューラル模型の作用構造を再注入する**逆転が起き得る。

v5では、

```text
機能再現 != 構成再現
```

を正本中核へ昇格した。

## 6. 「形成済み関係」の実体化問題

K3 / Llama / K2等でtraining後のweight差が能力差へ関与することは強く支持される。

しかしweight全量について「どの内部方向がどの意味関係を保持するか」は未観測と各構文化自身が認めている。

それにもかかわらず正本で形成物一般を `形成済み関係` と呼ぶと、**形成後模型状態に意味関係が物として格納されている**という一段強い存在論へ滑りやすい。

v5では上位語を `形成済み模型状態` とし、特定意味関係との対応が観測できた部分だけを `形成済み関係` と呼ぶ。

## 7. 模型境界の誤り

v4は検索service、tool、long-term memory等を典型的利用外周としていた。

一般的なproduct構成では有効だが、REALMはretrieverをpre-training・fine-tuning・inferenceへ統合し、RETROもretrieval database参照をlanguage model architectureへ組み込む。

従って、

```text
retrieval = 外部
```

という部品種別分類は成立しない。

v5では模型境界を、

- 同一性固定
- 実行必須性
- 形成結合
- 介入影響
- 展開任意性

で判定する。

## 8. 規模三面の誤り

v4の `状態域規模 / 関係域規模 / 共有適用規模` は機能規模を観測するには有用だった。

しかし実際のLarge Language Modelという慣用は、parameter数、training data、compute、model artifact等の物理・形成規模とも強く結びついている。

三面だけで `large` を閉じると、外部慣用から離れた独自定義になる。

v5では固定三面を解除し、尺度・比較集合を宣言する `規模プロファイル` へ変更した。旧三面は機能規模の補助観測として残す。

## 9. architecture横断テスト

### Llama 3

standard decoder-only Transformer。自己回帰は有力な成立形だが普遍必須ではない。

### BERT

deep bidirectional representationとmasked language modeling。外部文章生成をLM成立必須にできない。

### T5

text-to-text architecture。変換型も同じ言語状態域関係として記述可能。

### RWKV

TransformerとRNNの計算形を接続し、recurrent inferenceを成立させる。Transformer物理形は普遍条件でない。

### LLaDA / iLLaDA

masked diffusion / bidirectional attentionで強いlanguage modelingを成立させる。autoregressive factorizationは普遍条件でない。

### REALM / RETRO

retrievalをlanguage modelの学習・推論へ組み込む。知識のparametric storage、外部tool分離を普遍条件にできない。

### 横断結論

共通して残るのは特定部品ではなく、**構成可能な言語状態域に対し、入力・文脈に応じた言語状態差を形成し、それを広い未列挙状態へ再利用して言語状態へ接続する模型性**である。

## 10. v5採否

### 廃止 / 位置変更

- 言語模型性五条件 → 廃止
- 構成再現七条件 → 普遍条件から観測軸へ降格
- 規模三面 → 普遍固定面から補助観測へ降格
- 形成済み関係 → 上位概念を形成済み模型状態へ変更
- retrieval等の部品種別による外周分類 → 廃止

### 新設

- 言語模型性四条件
- 識別監査条件
- 機能再現 / 構成再現の分離
- 元模型相対の構成再現対象プロファイル
- 構成不変量の因果認定
- 模型境界五軸
- 規模プロファイル

## 11. MINIDORAへの影響

現行MINIDORAは、v4の構成再現適合を満たすために元LLMの状態保持・再作用構造を模倣することを第一目的にしてはならない。

次回MINIDORA監査では、まずv5四条件に対して、

```text
入力 / Data
→ 言語状態域の構成
→ 条件付き言語差形成
→ 未列挙状態への構成再利用
→ 言語状態接続
```

が成立しているかを見る。

その上で、推論・知識・長文等の対象能力ごとに必要な内部構成を独立に設計・検証する。

## 12. 判定

- v4を境界精密化だけで維持する方針: **撤回**
- v4五条件を模型成立条件として維持: **不採用**
- v4七条件を普遍構成再現条件として維持: **不採用**
- v5四条件 + 識別監査分離: **現時点採用**
- v5構成再現の元模型相対化: **現時点採用**

確信度目安: **94%**

残差:

- 「言語状態接続」がcompiler / transducer等との境界を十分に分けるかは、追加反例監査余地がある。
- `large` の外部慣用は時代・分野で変化するため、規模プロファイルは継続再開放対象とする。
