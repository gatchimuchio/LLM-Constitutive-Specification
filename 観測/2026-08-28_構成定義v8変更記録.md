## 2. 改定契機

二つの独立した差を契機とした。

### 2.1 日本語基底の不徹底

`規定/00_規定言語.md` 自体は日本語先行を規定していたが、後続の正本・索引・監査器に、`local-to-global`、`scorer`、`representation`、`runtime` 等の外部語が内部座標として残っていた。

最上位理論正本 `cognitive-engineering-foundations` の現行言語原則は、

```text
日本語で理論生成
→ 日本語で定義・構造化
→ 日本語で監査・改訂
→ 日本語原典成立
→ 実務上必要な場合のみ多言語へ翻訳
```

である。

従って、外部語を対照名へ降ろし、日本語だけで正本意味を再構成できる状態へ修正した。

### 2.2 能力作用観測の粒度不足

MINIDORA側のK3除外10模型再構文化v3とGPQA実測から、旧規定の「能力」章では次を分け切れていないことが露出した。

- 状態が存在する
- 状態が後続で使われる
- 参照が変わる
- 経路が変わる
- 計算量が変わる
- 過去状態を再参照する
- 複数結果を再結合する
- どの尺度で循環する

そこで `規定/07_能力作用構成.md` を追加した。

## 3. v7から維持した中核

次は維持した。

```text
完全言語状態空間
+ 持続模型状態
→ 一つの整合した言語確率法則
```

理由:

- n-gram等の既知言語模型を含められる。
- 任意得点器を厳密言語模型から分離できる。
- 可変長終端を監査できる。
- 条件付き言語模型・伏字予測・言語表現模型等を隣接分類として分けられる。
- 今回の能力作用観測は、この中核を崩す反例ではない。

## 4. v8で変更したもの

1. `cognitive-engineering-foundations` を最上位理論正本として明示。
2. 日本語を唯一の基底・規定言語として全正本へ貫通。
3. 外部語を意味正本から外部対照名へ降格。
4. `local-to-global接続` を `局所条件から完全法則への接続` へ改定。
5. `言語score関係` を `言語得点関係` へ改定。
6. `規模プロファイル` を正本語として使わず `規模記述` へ改定。
7. 能力作用構成を独立正本化。
8. 固定された「再開放順序」を廃止し、再開放座標＋循環再帰へ変更。
9. 構成定義・構文化・実装・実測を固定直列ではなく相互帰還関係として明示。

## 5. MINIDORA実測の扱い

参照実測:

```text
中間状態保存数        = 815
保存状態の再利用      = 0
全体再照合            = 0
候補横断更新          = 0
専門作用呼出          = 0
```

この観測から直接採用したのは、

> 状態の存在と後続利用は同一ではない。

という分別である。

GPQA低得点の単独原因を「再利用0」とは確定していない。
