# 構成定義 v6 独立再監査 — 2026-08-28

## 0. 監査方針

v5を正解として扱わず、旧Layer-0仕様、n-gram、BERT/MLM、compiler/transducer、retrieval統合系、K3/横断構文化、MINIDORA失敗実測を独立に再突合した。

下流性能へ正本を合わせず、下流失敗は反例探索の入口にのみ使う。

## 1. 参照した主要資料

### プロジェクト内

- v5正本
- 旧Layer-0六役仕様系列
- K3 D4能力成立作用構文化
- K3以外複数LLM横断能力成立作用構文化
- MINIDORA GPQA / 再作用失敗記録
- 非ニューラルReference-driven LM MVP

### 外部

## 2. v5の誤り1 — 構成再利用を普遍LM条件へ置いた

v5は未列挙状態へ同じ作用を再利用できることをLM成立の中核へ置いた。

しかしn-gramは標準的language modelであり、有限count/tableへ強く依存する。強い未列挙一般化能力をLM性と同一視すると、既知のLMを能力不足を理由にカテゴリ外へ落とす。

### 修正

`構成再利用` を普遍中核から外し、一般化能力・規模へ移した。

## 3. v5/v6初稿の誤り2 — 言語状態接続 / 言語代替関係が広すぎる

「言語状態を出力できる」「言語代替を相対化できる」だけでは、compiler、spell checker、task ranker等まで入る余地がある。

### 修正

中心を **条件付き言語重み関係** とし、これが候補系の内部実行意味として先に存在することを要求する。

一意出力を後からデルタ分布へ読み替えてLM化する操作を禁止した。

## 4. 誤り3 — 局所条件分布と完全LMを混同

BERT原論文はBERTをlanguage representation modelと呼ぶ。さらにACL 2023の研究は、masked LMの局所条件分布群が完全なlanguage distributionを自動的に定義しないことを明示する。

### 修正

- BERT encoder artifact
- MLM pre-training system / 局所言語模型作用
- MLMから完全系列modelを導出した系

を分離した。

## 5. 誤り4 — 条件付き言語代替の「複数候補」自体を中心にした

候補数ではなく、模型の実行意味として言語状態空間へ相対重みを与えることが本質である。

### 修正

```text
言語状態空間 + 文脈 + 持続模型関係
→ 条件付き言語重み関係
→ 完全言語状態またはそれを形成する過程へ接続
```

へ変更した。

## 6. 誤り5 — 構成因果要素と必要条件をまだ分け切れていなかった

ablationで性能が下がれば因果寄与は支持できる。しかし冗長経路・代替実装・補償作用があるなら必要とは限らない。

### 修正

```text
構成因果寄与 != 構成必要条件 != 構成不変量
```

を固定した。

必要条件は、宣言境界内で機能同値物を含む代替まで監査して初めて採用する。

## 7. 誤り6 — 構成再現を能力因果再現へ狭めすぎた

構造忠実度そのものを目的とする再現も正当である。一方、構造が同じでも因果的役割が同じとは限らない。

### 修正

- 構造再現
- 因果機構再現
- 機能再現
- 能力再現

を分けた。

## 8. 模型境界 — v5の修正は維持するが三層を明確化

v5の「retrievalを部品名だけで模型外へ追い出さない」は維持できる。

ただし単一模型境界では、保存artifactと固定実行依存を混ぜる。

### 修正

```text
言語模型物 != 言語模型実行系 != 利用系
```

を正本化した。

REALM等ではretrieverが実行系へ不可分でも、knowledge corpus全量が直ちに模型物になるとは限らない。

## 9. Large / LLM呼称

v5の「言語模型機能と現代LLM呼称を分ける」は維持できる。

ただし規模は模型物を中心にし、任意外部Web/corpusや利用系の巨大さだけでsmall coreをLargeへ昇格しないよう強化した。

## 10. MINIDORAへの帰結

MINIDORAについて最初に監査するのは、

```text
言語模型機能成立
```

である。

GPQAは能力監査。既存NNのstate/reaction構造をコピーする必要はない。

ただしMINIDORAが一意textを生成できるだけではLM成立証拠にならない。内部に条件付き言語重み関係、またはそれと機能同値な明示的言語状態相対化が実在するかを確認する必要がある。

これは旧Reference-driven non-neural MVPの `fitted non-neural conditional token surface` と直接照合可能である。

## 11. 旧六役Layer-0との比較

旧六役はoperational generative LLMへ強く寄っており、decoder/emission・fitting criterion等を含んでいた。

v6はLM一般の中核と、生成運用・形成・Large呼称を分けるため六物理役をそのまま復活させない。

一方、旧仕様が保持していた **conditional linguistic surface** という中心は、今回の `条件付き言語重み関係` と整合する。旧仕様の全部が誤りだったのではなく、カテゴリ境界が広すぎる/狭すぎる部分を再分別したと判断する。

## 12. 残差

現時点で残る主な再開放点:

1. unnormalized energy / ordinal symbolic weightingをどこまでLM一般へ含めるか。
2. Masked LMという業界慣用と、完全distributionを持つLMという厳密区別の名称衝突。
3. 非ニューラル系が外部慣用で無修飾LLMと呼ばれる条件。
4. `Large` の普遍閾値は存在しないため、比較集合と慣用依存が残る。

これらは現時点で論理矛盾ではなく、射程・用語慣用の未固定域として残す。

## 13. 判定

- v5四条件維持: 不採用
- v6初稿三関係をそのまま維持: 不採用
- 条件付き言語重み関係中心へ再構成: 採用
- n-gram positive control: 採用
- compiler posthoc-delta禁止: 採用
- BERT encoder / MLM / derived LM分離: 採用
- 模型物 / 実行系 / 利用系三層: 採用
- 因果寄与 / 必要性 / 不変量分離: 採用
- 機能 / 能力 / 構造 / 因果機構再現分離: 採用

確信度目安: **95%**
