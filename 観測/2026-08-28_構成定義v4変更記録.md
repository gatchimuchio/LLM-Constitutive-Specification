# 構成定義 v4 変更記録 — 2026-08-28

## 1. 旧版 / 新版

- 旧版: `2026-08-27-成立規定-3`
- 新版: `2026-08-28-成立規定-4`
- 正式名称: 大規模言語模型成立規定
- 状態: 局所安定正本 / 再開放可

## 2. 変更対象

v3で確定した言語模型性の五条件と構成再現の七区別は維持した。

今回変更したのは、七区別のうち特に次の語を下流実装へ写像するときの成立境界である。

- 状態保持・状態更新
- 構成連鎖
- 再作用・再参照・再結合
- 終端閉包

追加した主要語彙:

- 作用状態
- 評価メタデータ
- 状態差
- 作用
- 状態遷移
- 内生形成

## 3. 再開放理由

v3は、独立LLM横断構文化から得られた次の作用を正本へ戻していた。

```text
入力差
↓
状態保持
↓
局所更新・選択参照
↓
大域再照合
↓
深さ方向の累積・混合
↓
未確定差を残したまま再作用
↓
出力に必要な差が形成される
```

一方、MINIDORA下流監査では、部品テストで状態保持・checkpoint・再作用等を満たしたように見えても、実入力で再利用・再作用が発火しない事例が確認された。

既存の保存済み監査でも、`NOTNN-LLM-MINIDORA` commit `61cba4192183ee7fcc6e7244b55f098daa8020a6` では、Working Relation Storeとcheckpointは形成されたが、working relations reused = 0、checkpoint reactivations = 0、global reconciliations = 0であり、「記録された状態」と「後段から実効利用された状態」が分離していた。

さらに2026-08-28の下流監査では、構成再現v3のunit/component testが全面通過していても、実問題上では前段状態差が後段作用条件へ接続されず、再作用が実質的に候補再評価・寄与加算へ縮退し得ることが確認された。

この問題はbenchmark点数そのものではなく、**v3の語義を満たしたと実装側が判定できる余白が広すぎた**ことを示す。

## 4. 独立構文化との照合

正本変更は下流結果だけで行っていない。

既存の独立構文化にはすでに、

- intermediate state retention
- repeated reaction
- past state reaccess
- late commitment
- common / conditional action recombination
- input differenceを複数段の内部状態変換へ渡す経路

が抽出されている。

したがって今回追加した「作用状態」「実効状態遷移」「前段差が後段作用条件を変える」「checkpoint実効再利用」「入力境界からの内生形成」は、新しい物理部品仮説ではなく、v3で採用済みの作用を下流へ損失なく射影するための精度境界である。

## 5. v4で固定した非同一性

### 作用状態 != 評価メタデータ

得点、順位、寄与値、回数、ログ、監査理由等は有用だが、それだけで作用状態とはしない。

### 状態遷移 != 得点更新

候補得点・順位・寄与値だけが変わり、後段作用の入力・適用条件・利用可能性・制約・終端が変わらない場合、それだけでは状態遷移としない。

### 再作用 != 再採点

同一状態へ同一評価器を再適用し、評価メタデータを再計算・加算するだけでは再作用としない。

### checkpoint保持 != 実効再利用

checkpointや履歴が保存・計数されるだけでは足りず、後段が読み出し、その内容差で後続作用が変わることを要求する。

### 再結合 != 最終得点合算

複数寄与を合算すること自体は許すが、合算結果が後続作用の新しい入力・条件・制約・成立差へ接続しない場合、構成連鎖上の再結合の十分条件ではない。

### 端到端構成再現 != fixture後段適合

目的の関係・中間状態をfixtureへ事前注入し、その後段処理が動くことは部品適合である。端到端構成再現では、宣言した入力 / Data境界から必要な中間状態・状態差・作用条件が内生形成されることを要求する。

## 6. 七条件の扱い

**v3の七区別は維持**する。

v4は条件数を増やす改定ではなく、七条件が実装時に何を意味し、何では満たされないかを固定する改定である。

これにより、v3までの独立構文化・関係写像・過去判定を無言で破棄しない。

## 7. 影響範囲

影響する:

- 構成再現適合の監査
- 下流模型への仕様射影
- 状態保持・更新・再作用・再結合を名乗る実装の受入条件
- component testと端到端構成再現の分離

影響しない:

- 言語模型性の五条件
- 大規模性の三面
- 生成運用性の分離
- 特定Transformer / Attention / MoE等を普遍必須にしない原則
- v3以前の観測記録そのもの

## 8. 旧判定への影響

v3で「言語模型性が成立」とした判定は、本改定だけでは変更しない。

v3で「特定LLMの構成再現適合」とした下流実装については、作用状態 / 評価メタデータ分離、状態遷移、実効再作用、内生形成の追加境界で再監査が必要になり得る。
