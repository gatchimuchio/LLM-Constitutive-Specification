# 構成定義 v7 独立再監査 — 2026-08-28

## 0. 方針

v6を正解扱いせず、v6残差、旧Layer-0、n-gram、BERT/MLM、diffusion LM、energy-based LM、probabilistic grammar、compiler/transducer、MINIDORA失敗実測を独立再突合した。

## 1. v6誤り1 — 「言語重み」が広すぎる

v6はprobabilityだけでなくscore、ordinal、energy等を同じ中核へ入れた。しかし標準的LMは文字列/系列へのprobability distributionとして定義され、energy-based LMもenergy単体ではなくglobal normalized distributionを形成することでLMになる。

したがって arbitrary score をLM一般へ含めるのは過剰一般化だった。

### 修正

厳密LM中核を `完全言語状態上の整合した言語確率法則` へ変更した。

## 2. v6誤り2 — weighted grammarの一括positive化

任意semiring weighted grammarは確率法則を定義しない場合がある。probabilistic grammar / normalizable weighted grammarと、それ以外のweighted scorerを分ける。

## 3. v6誤り3 — 可変長の閉包不足

n-gram等でEOS/length lawがない場合、全長文字列を通じた一つの確率分布ではなく、長さごとの分布に留まり得る。

### 修正

可変長LMではEOS、停止法則、長さ分布等を監査対象へ追加した。

## 4. v6誤り4 — compiler境界の「delta禁止」は強すぎる

任意deterministic functionは数学上delta conditional distributionを誘導できる。従ってdeltaという形自体を禁止しても数学的境界にはならない。

### 修正

退化分布そのものは禁止しない。模型仕様として言語分布を退化分布で定義する条件付きLMは成立し得る。

一方、posthoc deltaは「LMである証拠にならない」とする。入出力写像だけではdeterministic transducerと退化条件付きLMを一般に分離できないため、条件付きLM分類にはmodel specification / formation target / internal relationとしてtarget language distributionを模型化している独立証拠を要求する。

## 5. v6誤り5 — MLMを「局所LM作用」と呼ぶ語義

MLMはlocal conditional predictionを持つがjoint distributionを自動定義しない。`局所言語模型作用` はLMという語を先に含み、誤読余地がある。

### 修正

`局所言語予測作用 / language-modeling objective` へ変更し、厳密LMから分離した。

## 6. v6誤り6 — 因果証拠の弱区分

source code / design文書は機構・意図を示せるが、因果効果を識別しない。

### 修正

設計文書の説明やsource codeの名称・存在だけを因果効果の証拠から外し、構造/意図証拠として扱う。因果寄与は介入または十分に統制された比較を主根拠とする。ただし実行意味から依存関係を形式的に導ける場合は、形式的機構根拠として利用できる。

## 7. 維持できたもの

- n-gramをLM一般から排除しない。
- BERT encoder / MLM / derived full LMを分離する方向。
- 模型物 / 実行系 / 利用系の三境界。
- LM性と能力・GPQAを分離。
- 機能 / 能力 / 構造 / 因果機構再現の四分。
- 因果寄与 / 必要性 / 不変量の分離。
- Large / 現代LLM呼称を別監査する。

## 8. 外部独立根拠

- Jurafsky & Martinのn-gram章はLMをnext-word/sequenceへのprobability assignmentとして説明する。
- ACL 2023 `Deriving Language Models from Masked Language Models` はMLMが明示的language distributionを定義しないためLM per seではないと分ける。
- LLaDAはdistributionをforward masking + reverse processでmodelすると明示する。
- energy-based LM文献はglobally normalized modelとして扱う。

## 9. MINIDORAへの影響

MINIDORAについて、単なるcandidate scoreや関係scoreが存在するだけでは厳密LM成立としない。

必要なのは、宣言した完全言語状態空間へ一つの整合した法則を与えること、またはその法則を誘導する生成過程を明示すること。

GPQA推論設計はその後の能力層で独立に扱う。

## 10. 残差

- conditional LMとgeneric probabilistic transducerの語用境界は、model targetの観測に依存する。
- 現代技術用語としてMLM/BERTをlanguage modelと呼ぶ広義慣用は残るため、厳密分類と慣用分類を併記する。
- 非ニューラル系の無修飾LLM呼称は外部用例依存。

## 11. 判定

- v6条件付き言語重み中核: 不採用
- strict/global probability law中核: 現時点採用
- arbitrary scoreをLMへ含む: 不採用
- energy normalizability境界: 採用
- variable-length sample-space / termination監査: 採用
- delta禁止: 撤回し、退化分布を許容したうえでposthoc deltaを証拠不足へ変更
- design/sourceの記載だけを因果証拠扱い: 不採用
- executable semanticsによる形式依存根拠: 条件付き採用
