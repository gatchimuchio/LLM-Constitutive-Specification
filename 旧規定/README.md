## 扱い

旧規定は、

- 当時の観測
- 仮説
- 監査方法
- 失敗履歴
- 再現資産
- 比較資産

として価値を持つ。

ただし、現行規定へ自動継承しない。

旧観測を再利用する場合は、現行の日本語基底規定に従って、対象・関係・形成・運用・規模・外周へ再分別する。
