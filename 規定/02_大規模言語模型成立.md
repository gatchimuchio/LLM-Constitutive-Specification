# 大規模言語模型成立

## 目的

Large Language Model / LLM を、Transformer・ニューラル・自己回帰等の特定実装へ固定せず監査する。同時に、**厳密なlanguage model、局所予測/scoring系、能力、規模、現代LLM呼称、模型物と実行系、各種再現**を混同しない。

v7ではv6の `条件付き言語重み関係` 中心も保存しない。理由は、任意score・ordinal weighting・unnormalized energyまで同じ中核へ入れると、標準的なlanguage modelの定義である「言語系列上の確率法則」と、単なるscorerを分けられないためである。

## 1. 最初に分ける

```text
A. 厳密言語模型か
B. 条件付き言語模型か
C. 局所予測 / scoring / representation / transductionのどれか
D. どの模型物 / 実行系で成立しているか
E. どの能力・規模・現代LLM呼称が成立するか
F. 何をどの忠実度で再現するか
```

## 2. 厳密言語模型の中核

現行版では、厳密なlanguage modelを次で閉じる。

```text
完全言語状態空間 L
+ 持続する模型状態 M
→ 一つの整合した言語確率法則 P_M(L)
```

### 2.1 完全状態上の法則

Language modelは、完全な文字列・token系列・文等へ確率を与える、またはそれと同値な生成過程によって確率法則を誘導する。

局所条件確率・next-token確率・diffusion transition等は、その全体法則をfactorizeまたは誘導する成立形である。

### 2.2 可変長

確率法則を定義する**標本空間そのものを先に固定する**。固定長系列、有限可変長系列、無限系列を同じものとして扱わない。

有限可変長系列を標本空間とする場合はEOS、停止法則、長さ分布等により総確率質量を閉じる。長さごとに別の分布しか定義しない場合は `length-conditioned language model` 等として範囲を明示する。無限系列を標本空間へ含める場合は、その測度空間を明示し、有限文字列LMと無言同一視しない。

### 2.3 正規化不能なscoreを分ける

任意のscore・順位・energyが存在するだけでは厳密LM成立としない。

energy-based LMはenergyそのものではなく、finite partition function等を介して完全系列上のglobal probability distributionを定義することでLMになる。正規化計算が実務上困難でも、**正規化可能な法則が定義されていること**と、単なるscoreしか無いことを分ける。

### 2.4 形成方式を固定しない

確率法則はneural weight、count、probabilistic grammar、table、graph、program等で実現できる。ニューラル学習・Transformerを普遍必須にしない。

## 3. 条件付き言語模型

外部条件 `c` に対してtarget言語状態 `y` の完全状態上へ `P_M(y|c)` を定義する系を条件付き言語模型とする。

translation等のconditional sequence modelは、この条件を満たす場合に条件付きLMとして監査できる。

### 3.1 deterministic transducerとの境界

任意のdeterministic function `y=f(c)` は数学上デルタ条件分布を誘導できる。したがって、**「デルタ分布を禁止すればcompilerを排除できる」というv6の閉じ方は不十分だった。**

**退化分布そのものは禁止しない。** 模型仕様としてtarget言語状態上の条件付き確率法則を最初から退化分布で定義する模型は、条件付きLMの成立形になり得る。

一方、事後的なデルタ表現は「確率分布として書ける」ことを示すだけで、その系がlanguage distributionを模型化していることを示さない。**入出力写像という外延だけでは、deterministic transducerと退化条件付きLMを一般には分離できない。**

従ってcompiler / deterministic transducerを条件付きLMと分類する場合は、変換結果だけでなく、模型仕様・形成対象・実行時の内部関係としてtarget language distribution自体を模型化している独立証拠を要求する。単なる意味論的写像は `言語変換模型` として分ける。

## 4. positive control

### 4.1 n-gram

n-gramは標準的LMである。条件付き次語確率をchain ruleで完全系列確率へ接続する。可変長ではEOS/長さ法則を含める。

### 4.2 causal autoregressive LM

next-token条件分布の積が完全系列分布を定義する典型例。

### 4.3 diffusion LM

LLaDA等のようにforward/reverse processを通じて完全言語状態のdistributionをmodelする系は、自己回帰でなくても成立する。

### 4.4 energy-based LM

energyからglobal normalized distributionを定義する場合にLMとして成立する。energyだけのscorerは別。

### 4.5 probabilistic grammar

導出確率から文字列確率が定義され、全対象状態で確率法則が閉じる場合にLMとなる。

## 5. boundary / negative control

### 5.1 arbitrary weighted grammar

任意semiringや順位だけを持つweighted grammarは、正規化可能な言語測度または確率法則を示さない限り厳密LMへ自動昇格しない。

### 5.2 classifier / ranker

外部task labelや候補scoreだけを返す系は、それだけでは完全言語状態の確率法則を定義しない。

### 5.3 parser / recognizer

membershipやparse treeを返すだけの系と、確率文法として文字列確率を与える系を分ける。

### 5.4 retriever only

既存record取得だけではLMではない。retrievalがLM実行系の確率法則形成へ組み込まれる場合は境界を別監査する。

## 6. BERT / MLM境界

BERT原論文はBERTをlanguage representation modelとして導入する。BERT encoder artifactとMLM objective/headを分ける。

Masked Language Modelingはmasked位置の局所条件予測を学ぶが、局所条件群だけでは一つのjoint distribution over languageを明示的に定義しない場合がある。

したがって、

- BERT encoder artifact: 言語表現模型。
- MLM objective/headを含む系: 局所言語予測・language-modeling system。
- MLMから整合したjoint/global distributionを別途導出した系: その導出を含めて厳密LM監査。

と分ける。

業界・論文で `masked language model` と呼ばれる慣用は記録するが、**慣用名と厳密LM性を同一の主張にしない。**

## 7. 模型物・実行系・利用系

```text
言語模型物 != 言語模型実行系 != 利用系
```

### 言語模型物

確率法則を担うweight、count、rule、table、graph、program等の持続模型状態。

### 言語模型実行系

模型物に加え、確率法則または生成法則を閉じるため固定的に必要なruntime、token mapping、retriever、index等を含む。

### 利用系

任意Web検索、agent loop、UI、approval、session memory、multi-model orchestration等。

retrieval等は部品名で内外を固定しない。

## 8. 形成済み模型状態

形成後に模型物へ持続する状態を `形成済み模型状態` とする。weight全量に意味関係が明示格納されていると未観測のまま仮定しない。

## 9. 能力を分離

```text
厳密言語模型成立
!=
高推論能力
!=
GPQA高得点
```

MINIDORAのGPQAは能力監査であり、厳密LM性の証人でも反証でもない。

## 10. 再現を四分

- **機能再現** — 指定したLM法則・入出力関係等の機能を再現。
- **能力再現** — 推論・知識・翻訳等の能力を再現。
- **構造再現** — 観測された構造を指定忠実度で再現。
- **因果機構再現** — 介入等から支持された因果関係を再現。

構造一致から因果同一性を導かず、因果機構同等から物理構造一致も導かない。

## 11. 因果寄与・必要性・不変量

### 11.1 因果寄与

直接介入、disable、controlled substitution、十分に統制された比較等から対象差への因果寄与を支持する。

**設計文書の説明やsource codeの名称・存在だけは、構造・意図の証拠であって因果効果の十分証拠ではない。** ただし、実行意味から依存関係を形式的に導ける場合、またはその依存を実行・介入で確認した場合は、機構的因果根拠として利用できる。

### 11.2 必要性

必要性は宣言した模型版・対象能力・許容介入集合に相対的に記述する。単一ablation低下から普遍必要性へ飛躍しない。

### 11.3 不変量

宣言したrealization変換集合に対して保存される性質をいう。因果寄与・必要性と別概念である。

## 12. 現代LLM呼称

厳密LMであることと、現在の技術慣用で `Large Language Model / LLM` と呼ばれることを分ける。

現代LLM呼称適合では、少なくとも模型物規模、形成規模、言語範囲、現在の技術用例を確認する。

非ニューラル系が厳密LM機能や参照LLMの機能を再現しても、無修飾LLM呼称が社会的・技術的に定着しているかは別監査とする。

## 13. 大規模性

`03_規模記述.md` に従う。比較集合を結果後に恣意的に縮小しない。模型物・形成・実行系・利用系を分ける。

## 14. 識別監査

厳密LM性を採用する最低監査:

1. 完全言語状態空間を先に固定する。
2. 候補模型がその空間上へ一つの整合した確率法則を定義するか確認する。
3. 局所条件や生成遷移しか見えない場合、それらがglobal lawを誘導する接続を確認する。
4. 標本空間を固定し、有限可変長ならEOS/停止/長さ法則、無限系列を含むならその測度空間を確認する。
5. score/energyだけなら正規化可能性または明示的global modelを確認する。
6. MLM局所条件をjoint distributionへ無言昇格しない。
7. deterministic transducerの事後デルタ表現だけをLM証拠にしない。
8. n-gram等の既知LMを方式名で排除しない。
9. 同一条件で再確認できる。

## 15. 現行閉包

```text
[厳密LM]
完全言語状態空間
+ 持続模型状態
→ 整合した言語確率法則

[成立形]
autoregressive factorization / diffusion / energy normalization /
probabilistic grammar / count model / その他法則同値物

[別カテゴリ]
局所予測 / score / representation / transduction

[別軸]
能力 / 規模 / 現代LLM呼称 / 模型境界 /
機能・能力・構造・因果機構の再現
```

## 16. 短縮定義

### 厳密言語模型

> **厳密言語模型とは、明示した完全言語状態空間について、持続する模型状態により一つの整合した確率法則を定義する模型である。局所条件・energy・生成遷移等は、その法則をfactorizeまたは誘導する成立形として扱う。**

### 大規模言語模型

> **大規模言語模型という呼称は、厳密LM性または現在用例上これと同等と扱われるlanguage-modeling coreに加え、規模プロファイルと現在の技術用例を別監査して採用する。**
