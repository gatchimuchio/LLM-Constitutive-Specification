# 大規模言語模型成立

## 目的

現在 Large Language Model / LLM と呼ばれている実在系を、特定のニューラル構造・学習方式・確率表現へ固定せず、**何が言語模型として成立しているのか、何がその識別監査なのか、何が特定模型の機能・構成再現なのか**を分けて規定する。

v5では、v4までの五つの言語模型性成立条件と七つの構成再現条件を正本前提から外した。理由は、前者が模型内在条件と監査条件を混在させ、後者が実在高能力LLMから得た観測軸を普遍構成条件へ昇格していたためである。

## 1. 三つを最初に分ける

```text
言語模型として成立しているか
!=
その成立を外部から確認できるか
!=
特定の既存LLMを機能または構成として再現しているか
```

1. **言語模型性** — 模型そのものについての成立条件。
2. **識別監査** — その成立条件を外部から循環なく確認する条件。
3. **再現適合** — 元模型または元能力を別模型で再現する場合の条件。

この三層を同一の条件表へ入れない。

## 2. 対象言語体系

自然言語、プログラム言語、その他の明示された言語体系を対象にできる。

任意の固定ラベル・ID・数値列を名称だけで言語へ昇格しない。候補模型を見る前に、対象言語体系と、どの状態を同じ言語状態域として扱うかを宣言する。

## 3. 言語模型性の成立条件

現行版では、模型内在条件を次の四条件へ整理する。

### 3.1 言語状態域

模型の対象が、宣言した言語単位から構成される言語状態域であること。

固定された少数のタスクラベルや既存レコードだけを対象とする処理系は、それだけでは言語模型性を満たさない。

### 3.2 条件付き言語差形成

入力・文脈・現在状態の差に応じて、同一言語状態域に属する未確定状態の間へ成立差を形成できること。

成立差は、継続、補完、復元、変換、整合、制約、適合等として現れ得る。確率分布、logit、sampling等の特定表現を普遍必須にしない。

### 3.3 構成再利用

同じ模型側作用または模型側関係が、個別に完全列挙されていない複数の言語状態・文脈・組合せへ再利用できること。

完全個体の検索表、固定FAQ、全ケース手書き分岐等だけでは、この条件の十分な証拠にならない。

### 3.4 言語状態接続

模型内部で形成した差が、宣言した言語状態域に属する状態の選択・形成・補完・復元・変換・更新へ接続できること。

外部タスクの固定ラベルだけを終端とし、模型自身に言語状態域への接続が無い場合、それだけでは言語模型性を満たさない。

## 4. 四条件の意味

四条件は四つの物理部品を要求しない。一つの機構が複数条件を担ってよく、複数機構が一条件を共同で担ってよい。

```text
言語状態域
  ↓ 文脈・入力差
条件付き言語差形成
  ↓
構成再利用
  ↓
言語状態への接続
```

これは固定実行順ではなく関係を示す図である。

## 5. v4五条件から外したもの

v4の次の三語は重要だが、模型内在条件ではなく識別監査へ移す。

- **独立対象** — 候補模型を見る前に監査対象を固定する方法論。
- **言語対応** — 模型内部差と対象言語側の差を外部から追跡する監査境界。
- **局所対応** — 現在証拠から模型と対象言語関係の対応を採用できる監査状態。

また、旧 `文脈依存関係` は3.2へ、旧 `関係再利用` は3.3へ吸収する。

したがって、

```text
旧五条件 = 模型成立条件ではない
```

とする。旧版の監査記録は履歴として保存する。

## 6. 方式非依存性の確認

現行四条件は、少なくとも次の異種模型を同じ物理構造へ固定せず記述できることを要求する。

- decoder-only causal LM
- masked / bidirectional LM
- encoder-decoder text-to-text LM
- recurrent LM
- masked diffusion / diffusion LM
- retrieval-integrated LM
- 非ニューラル、規則、表、グラフ、混成系

Transformer、Attention、RNN、MoE、自己回帰、拡散、確率分布、softmax、sampling、学習済みであることを普遍必須にしない。

## 7. 非言語模型・狭い処理との境界

次は、それ単独では言語模型性の十分条件にならない。

- 固定ラベル分類のみ
- 数値計算のみ
- 既存文書の検索・返却のみ
- 固定FAQ・完全個体lookupのみ
- tokenizerやparser等の前処理だけ
- 外部言語模型の結果をそのまま転送するwrapperだけ

ただし、これらの部品がより大きい模型の一部として四条件の成立へ不可分に参加する場合、その模型全体の境界は別に判定する。

## 8. 形成済み模型状態と実行作用

模型の現在能力を、`作用機構 + 形成済み関係` という固定二分だけで記述しない。

形成過程の結果として現在模型物に残るものを上位概念 **形成済み模型状態** とする。ニューラル重み、規則、表、グラフ、索引、コンパイル済み構造等を含み得る。

そこに特定の意味関係が格納されていると確認できた場合だけ、局所的に **形成済み関係** と呼ぶ。

```text
形成履歴
  ↓
形成済み模型状態
  ×
実行作用
  ×
入力・文脈
  ↓
実行時の状態差・成立差
```

形成済み模型状態を、観測していない意味構造へ昇格しない。

## 9. 模型境界

検索、memory、router、adapter、tool等を部品種別だけで模型外周へ追い出さない。

ある要素が模型の一部かは、少なくとも次で判定する。

1. 版・模型同一性として固定されているか。
2. 通常推論でその模型側関係を成立させるために必須か。
3. 形成過程で他部と共同最適化・共同構成されているか。
4. 除去・交換により言語模型性四条件の成立関係が変わるか。
5. 外部利用者が任意に交換できる展開後部品か。

REALMやRETROのようにretrievalが模型の学習・推論構造へ組み込まれる例があるため、`retrievalだから模型外` とはしない。一方、任意のWeb検索toolを後付けしただけなら通常は利用外周へ寄る。

## 10. 生成運用性

外部文章生成を言語模型性の必須条件にしない。

masked LMのように欠損位置の言語状態差を形成する模型も言語模型になり得る。外部へ言語状態を確定・反復形成する性質は生成運用性として別記録する。

## 11. 機能再現と構成再現を分ける

### 11.1 機能再現

別模型が、対象とした元模型または元能力について、入力・文脈差に対する言語状態域上の成立差形成を再び成立させること。

内部構造の一致を要求しない。

**非ニューラル代替模型が既存LLMの内部部品をコピーせず、同じ言語模型機能を別原理で成立させる場合、第一の目標は機能再現である。**

### 11.2 構成再現

元模型について直接観測された内部構成のうち、対象能力成立へ因果的に関与する差を、宣言した範囲で再び成立させること。

構成再現は元模型相対であり、普遍の固定七条件を置かない。

## 12. 構成再現対象プロファイル

構成再現を主張する場合、元模型ごとに次を固定する。

- 元模型・版
- 対象能力・対象範囲
- 観測深度
- 観測できた内部状態・作用
- 介入・除去・比較で因果関与を支持する構成不変量
- 未観測範囲
- 再現対象外
- 受入条件

内部構造が閉鎖されている模型について、出力類似だけから構成再現を主張しない。機能再現までに留める。

## 13. 構成観測軸

v3/v4で七条件として固定していた項目は、実在LLM群を比較するための**構成観測軸**へ降格する。

代表軸:

1. 状態の分離・保持・輸送
2. 状態遷移・更新
3. 意味・対象同一性の追跡
4. 複数未確定差・複数経路の共存
5. 寄与調整・選択・条件付き作用
6. 再作用・再参照・再結合
7. 形成済み模型状態と実行作用の関係
8. 終端・確定・出力接続
9. 入力境界からの内生形成
10. 作用範囲・局所/広域・深さ/幅等の作用域

これらは監査語彙であり、全模型へ同じ数・形・順序を要求しない。

## 14. 構成不変量の採用条件

ある観測軸を元模型の構成不変量として採用するには、少なくとも次のいずれかを要求する。

- 除去・無効化で対象能力または対象言語関係が系統的に変化する。
- 介入した状態差に応じて後段状態・出力差が追従する。
- 同型の対照模型との比較で、対象構成差と能力差の接続が再現する。
- 元実装・設計資料で当該作用が明示され、実測と整合する。

単なる存在、回数、ログ、クラス名、物理部品名だけでは構成不変量へ昇格しない。

## 15. v4七条件の扱い

v4の七条件は削除ではなく、**普遍条件から履歴的観測軸へ位置変更**する。

特に、

- 状態保持
- 未確定差共存
- 寄与調整
- 再作用・再結合
- 終端遅延

はK3その他の高能力LLMで重要な作用として観測されている。しかし、それは「すべてのLLMの構成再現に同一条件として必要」という意味ではない。

## 16. 識別監査

言語模型性四条件を外部から確認するため、次を監査する。

1. **独立対象固定** — 候補出力を見てから言語状態域を都合よく変えない。
2. **言語対応** — 内部差と対象言語状態差の対応を追跡する。
3. **差分追従** — 文脈・入力を変えると成立差が関係に沿って変わる。
4. **複数対照再利用** — 同じ模型側作用が複数の独立状態へ再利用される。
5. **未列挙構成監査** — 完全個体lookupで説明できない未列挙の組合せへ作用できる。
6. **再現性** — 同じ条件で同じ関係または同じ関係傾向を再確認できる。

これらは模型の物理部品ではなく、成立主張を支える監査条件である。

## 17. 大規模性

`大規模` を言語模型性の追加構成条件にしない。

規模は `03_規模記述.md` の規模プロファイルで別記録し、どの尺度・比較集合に対して大きいと呼ぶかを明示する。

## 18. 現行閉包

```text
[模型内在]
言語状態域
+ 条件付き言語差形成
+ 構成再利用
+ 言語状態接続
= 言語模型性

[外部監査]
独立対象固定
+ 言語対応
+ 差分追従
+ 複数対照
+ 未列挙構成監査
+ 再現性
= 言語模型性を採用する証拠

[別軸]
規模プロファイル
= 大規模という相対記述
```

## 19. 短縮定義

### 言語模型

> **言語模型とは、宣言した構成可能な言語状態域について、入力・文脈差に応じて未確定な言語状態間の成立差を形成し、その作用を未列挙の複数状態・文脈へ再利用し、形成した差を同じ言語状態域の選択・形成・補完・復元・変換・更新へ接続できる模型である。**

### 大規模言語模型

> **大規模言語模型とは、上記の言語模型性が成立し、明示した規模プロファイルと比較集合に基づいて大規模と位置づけられる模型である。**

### 構成再現

> **構成再現とは、元模型について観測された対象能力に因果的に関与する構成不変量を、元模型相対の再現対象プロファイルに従って別模型で再び成立させることである。**
