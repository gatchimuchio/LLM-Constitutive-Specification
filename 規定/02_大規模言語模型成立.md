# 大規模言語模型成立

## 目的

Large Language Model / LLM を、Transformer・ニューラル・自己回帰・確率分布の特定実装へ固定せず監査する。同時に、**言語模型機能、能力、規模、現代LLMという呼称、模型物と実行系、機能再現と内部再現**を混同しない。

v6独立再監査ではv5の四条件も保存しなかった。特に `構成再利用` と `言語状態接続` を言語模型一般の普遍条件へ置いたこと、BERT系MLMを完全なLM成立証人へ広く扱ったこと、構成因果寄与と必要性を十分に分けていなかったことを修正する。

## 1. 先に分ける層

```text
A. 言語模型機能が成立しているか
B. どの模型物 / 実行系で成立しているか
C. どの能力が成立しているか
D. どの意味で「Large / LLM」と呼ぶか
E. 参照模型を機能・能力・構造・因果機構のどの意味で再現するか
```

この五層を一枚の必要条件表へ混ぜない。

## 2. 言語模型機能の中核関係

現行版では、言語模型機能を固定個数の物理部品ではなく次の関係で規定する。

```text
言語状態空間 L
+ 文脈 c
+ 持続する模型関係 M
→ 条件付き言語重み W_M(. | c)
```

### 2.1 言語状態空間

模型化対象が明示された言語体系上の状態であること。

### 2.2 条件付き言語重み

模型自身の実行意味として、文脈に応じて言語状態へ確率・score・順序・energy・生成遷移等の相対重みを与えること。

確率正規化は普遍必須にしない。ただし、任意装置が一つの出力を返した事実から、後付けで「その出力へ重み1、他へ0」と置いて言語模型へ昇格させない。

### 2.3 全体状態への接続

自己回帰factorization、target条件付きfactorization、diffusionの生成遷移等のように、局所作用しか直接返さない場合でも、それらが完全な言語状態・系列の重みまたは生成過程へどう接続するかを明示する。

局所条件分布群だけが存在し、完全状態へ整合したjoint / generative modelが定義されない場合は、**局所言語模型作用**として記録し、完全な言語模型と自動同一視しない。

### 2.4 持続模型関係

条件付き言語重みを決める関係が、weight、count、rule、table、graph、program等の模型状態に持続し、個別入力ごとに正解を外部注入する仕組みではないこと。

未列挙一般化は能力差であり、言語模型一般の普遍条件にしない。

## 3. positive control: n-gram / weighted grammar

n-gramは標準的なlanguage modelであり、有限履歴・count tableであることを理由に排除しない。文脈から次語へ条件付き確率を与え、系列確率へfactorizeできる。

同様に、probabilistic / weighted grammarが完全文字列・系列へ重みを与える場合は、その部分を言語模型として監査できる。

したがって、

```text
強い一般化能力 != 言語模型性
ニューラル学習 != 言語模型性
```

である。

## 4. negative control: compiler / transducer / classifier

### 4.1 compiler / deterministic transducer

外部意味論・変換仕様に従ってsourceから一つのtargetを決定するだけの系は、それだけでは言語模型ではない。

一意出力を事後的にデルタ分布へ読み替えることを禁止する。target alternativesへ模型自身が条件付き言語重みを与える部分が存在する場合、その部分を独立に監査する。

### 4.2 classifier

外部タスクラベルのscoreだけを返すclassifierは、それだけでは言語模型ではない。基底模型に言語状態空間上の条件付き重み関係が存在するなら、classifier headと基底模型を分ける。

### 4.3 parser / formal recognizer

文法membershipのaccept / rejectや構文木生成だけを行う系を、自動的に言語模型へ含めない。言語状態間へ相対重みを与えるweighted / probabilistic grammar等は別に監査する。

### 4.4 retriever

既存recordを検索して返すだけでは言語模型ではない。retrievalが言語重み形成へ不可分に統合される場合は実行系境界を再監査する。

## 5. BERT / Masked Language Modelの境界

BERT原論文はBERTを `language representation model` と呼ぶ。したがって **BERT encoder artifact** 単体と、Masked Language Modeling objective / headを含む **MLM pre-training system** を無言で同一視しない。

さらにMLMは各masked位置の条件分布を与えても、それらが一つの整合した完全系列分布を明示的に定義するとは限らない。このため、

- BERT encoder artifact単体: 言語表現模型として監査。
- MLM pre-training system: 局所言語模型作用を持つ系として監査。
- MLMから完全系列の重み・生成模型を導出した系: その導出を含めて完全な言語模型として監査可能。

と分ける。

`Masked Language Model` という慣用名だけを、完全な言語模型の存在証明にはしない。

## 6. 方式非依存性

現行中核は、少なくとも次の成立形を物理同型へ固定しない。

- n-gram / count LM
- causal autoregressive LM
- encoder-decoder conditional LM
- recurrent LM
- diffusion / iterative generative LM
- energy / unnormalized score LM
- weighted grammar LM
- retrieval-integrated LM
- 非ニューラル・規則・表・グラフ・混成模型

Transformer、Attention、RNN、MoE、自己回帰、確率正規化、softmax、sampling、ニューラル学習済みであることを普遍必須にしない。

## 7. 模型物・実行系・利用系

### 7.1 言語模型物

weight、count、rule、table、graph、program等、模型同一性を持続的に担う保存物。

### 7.2 言語模型実行系

模型物に加え、言語模型機能を実際に閉じるため固定的に必要なruntime、interpreter、token mapping、retriever、index、decoder等を含む実行境界。

### 7.3 利用系

任意Web検索、agent loop、UI、long-term task memory、approval、multi-model orchestration等の利用外周。

```text
言語模型物 != 言語模型実行系 != 利用系
```

同じ部品名でも、版同一性・実行必須性・共同形成・介入影響・利用者による交換可能性から位置づける。

## 8. retrieval統合系

REALM等ではretrieverがlanguage modeling signalと共同形成され、推論時の言語重み形成へ参加する。したがって `retrieval = 利用外周` と固定しない。

一方、knowledge corpus / indexが模型物そのものか、実行系固定依存か、外部更新可能状態かは別に記録する。巨大な外部corpusを無言で模型物規模へ加算しない。

## 9. 形成済み模型状態

形成後に模型物へ持続する状態を上位概念 `形成済み模型状態` とする。weight全量へ未観測の意味関係が明示格納されているとは仮定しない。

特定意味関係との対応が直接観測できた部分だけを局所的に `形成済み関係` と呼ぶ。

## 10. 言語模型機能と能力を分離

推論、知識利用、GPQA、長文処理、tool use等は別能力である。

```text
言語模型機能成立
!=
高推論能力
!=
特定benchmark高得点
```

MINIDORAのGPQA失敗を言語模型機能の不成立へ自動帰属しない。同時に言語模型機能成立をGPQA能力の証拠にも使わない。

## 11. 再現を四分する

### 11.1 機能再現

参照模型の指定した言語模型機能差を、別模型が宣言範囲で再び成立させる。

### 11.2 能力再現

参照模型の指定した推論・知識・翻訳・長文等の能力差を再び成立させる。

### 11.3 構造再現

元模型で直接観測された構造・接続・状態配置等を指定忠実度で再現する。対象能力への必要性を自動主張しない。

### 11.4 因果機構再現

元模型で介入・除去・統制比較等から支持された因果寄与関係を再現する。物理構造一致は必須ではない場合がある。

`構成再現` は上位語として残すが、無修飾で使わず構造再現か因果機構再現かを明示する。

### 11.5 MINIDORAへの射影

MINIDORAの第一判定は参照模型なしの **言語模型機能成立** である。その後、必要な能力を独立監査する。既存NNの内部構造を模倣することを第一目的にしない。

## 12. 構成因果寄与・必要性・不変量

### 12.1 構成因果寄与

要素・状態・作用への適切な介入で対象能力・内部状態・出力が系統的に変化する場合、因果寄与候補または因果寄与として採用できる。

### 12.2 構成必要条件

因果寄与より強い主張である。宣言した境界内で当該関係と機能同値な代替をすべて除いたとき対象能力が成立不能になることを要求する。

単一ablationで性能が低下しただけでは必要性を確定しない。冗長経路・補償・代替実装を監査する。

### 12.3 構成不変量

宣言した実現変更・比較範囲を通じて保存される性質。因果寄与や必要条件と別概念である。

例: Attentionという物理部品が変わっても、対象範囲で「前段文脈差を後段へ広域接続する作用」が保存される、など。

## 13. 因果証拠の強度

- **強**: direct ablation / disable / state intervention / controlled substitution。
- **中**: 十分に統制されたsame-family比較・自然実験で差が反復。
- **弱**: source code / design文書に意図が明示され、観測挙動と整合。

弱証拠だけで必要因果条件へ昇格しない。強証拠でも直ちに必要性とはしない。

## 14. 現代LLM呼称適合

言語模型機能が成立しただけで、無条件に現代技術用語の `Large Language Model / LLM` へ分類しない。

```text
言語模型機能成立
LLM機能等価
現代LLM呼称適合
```

を分ける。

非ニューラル模型が参照LLMの言語模型機能を別材料で成立させることは `LLM機能等価` を支持する。しかし外部慣用として無修飾LLMと呼ぶかは、規模と現在の技術用例を別に監査する。

## 15. 大規模性

`03_規模記述.md` に従う。

比較集合を結果を見てから小さく選ばない。模型物・実行系・利用系のどの規模を数えているかを明示する。任意外部Webやcorpusの規模だけで小さい模型物を `large` へ昇格しない。

## 16. 識別監査

言語模型機能成立の最低監査は次とする。

1. 対象言語体系・言語状態空間を先に固定する。
2. 模型が内部で条件付き言語重み関係を実際に定義していることを確認する。
3. 一意出力から事後的にデルタ重みを導入しない。
4. その重みが完全言語状態または完全状態を構成するfactorization / generative processへ接続するか確認する。
5. compiler / classifier / parser / retrieverのnegative controlを通す。
6. n-gram等の既知LMを方式名で誤排除しない。
7. 模型物・実行系・利用系を分離する。
8. 同一条件で関係が再確認できる。

未列挙一般化は能力・規模監査として追加する。

## 18. 短縮定義

### 言語模型

> **言語模型とは、明示した言語状態空間について、持続する模型関係により、文脈条件付きで言語状態へ相対的な重みを与え、その重み関係が完全な言語状態またはそれを形成する一貫したfactorization・生成過程へ接続する模型である。**

### 大規模言語模型

> **大規模言語模型という呼称は、言語模型機能の成立に加え、模型物を中心とした規模プロファイルと現在の技術用語上の参照集合に対する呼称適合を別に監査して採用する。**

### 構成再現

> **構成再現は、元模型の内部について何を保存するかを先に宣言し、構造再現または因果機構再現として忠実度を個別に監査する。**
