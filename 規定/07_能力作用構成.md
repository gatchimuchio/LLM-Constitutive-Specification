# 能力作用構成

> 状態: 能力観測の現行構成正本 / 厳密言語模型成立条件とは分離 / 意思決定構造とも分離

## 目的

言語模型の能力を、単なる最終正答率や「推論する」という総称だけで扱わず、**状態がどのように後続作用へ参加して能力差を生じさせるか**という観測単位へ分解する。

本書は厳密言語模型の成立条件を増やすものではない。また、意思決定原理そのものを定義するものでもない。

```text
厳密言語模型成立
≠
高能力
≠
特定の能力作用構成
≠
意思決定構造
≠
能力主体
```

## 1. 契機

K3を除く複数言語模型の再構文化と、MINIDORA v0.5 GPQA実測を照合した。

MINIDORAでは同一計測中に、

```text
中間状態保存数        = 815
保存状態の再利用      = 0
全体再照合            = 0
候補横断更新          = 0
専門作用呼出          = 0
```

が観測された。

この結果は、少なくとも当該実装について、**状態を作ることと、その状態が後続能力へ作用することは別である**と示した。

一方、既存言語模型側でも、固定された後段作用、状態依存の参照重み変更、参照集合選択、経路選択、持続状態更新、外部実行循環、形成循環等は同一構造ではない。

したがって現行正本では「再作用」を一語で扱わない。

## 2. 基本観測単位

### 2.1 状態担体

後続作用が参照可能な形で保持される状態または表象。

状態担体の存在だけでは能力寄与を確定しない。

### 2.2 作用

状態・参照・候補・経路・計算量等へ変化を与える処理。

### 2.3 状態差

作用前後に生じた差。

内部意味を直接観測できない場合、差の意味を勝手に補わず、差の存在・伝達・後続影響を分けて記録する。

### 2.4 後続利用

状態または状態差が、後続計算の入力・参照・重み・経路・計算量・形成更新等へ実際に参加すること。

### 2.5 参照変更

状態に応じて参照対象、参照集合、参照重みのいずれかが変わること。

### 2.6 経路変更

状態に応じて、実際に実行される後続作用経路が変化すること。

固定された作用列の後段へ状態が渡るだけの場合と分ける。

### 2.7 計算量変更

状態・入力条件・外部制御等によって、反復量、探索量、処理量等が変化すること。

### 2.8 再参照

過去状態、元資料、以前の参照対象等を後続段階で再び参照すること。

### 2.9 再結合

複数の状態差、参照結果、作用結果等を同一の判断・状態・候補関係へ合流させること。

## 3. 必須分別

少なくとも次を同一視しない。

```text
状態が存在する
≠ 状態が後続利用される

後続利用される
≠ 参照集合が変わる
≠ 経路が変わる

固定配置された後段作用
≠ 状態差によって新たに成立した作用

深さ方向の状態輸送
≠ 実行循環

外部実行循環
≠ 模型内部循環

形成循環
≠ 単一推論内循環
```

## 4. 循環尺度

同じ「循環」「再作用」に見える現象を少なくとも次へ分ける。

1. **深さ方向輸送** — 前段状態が固定された後段作用へ渡る。
2. **系列持続更新** — 系列位置をまたいで圧縮状態等を更新する。
3. **自己回帰履歴** — 既生成系列を次位置計算へ利用する。
4. **対話履歴再入力** — 過去対話を次の模型入力へ再投入する。
5. **内部反復** — 同一推論中に模型内部の作用を複数回回す。
6. **外部実行循環** — 模型外の実行器が出力・道具結果を見て次行為を選ぶ。
7. **形成循環** — 実行結果や生成資料が次の模型形成へ戻る。

方式名ではなく作用関係で分類する。

## 5. 現時点の横断候補

複数模型の観測から、次を能力作用の横断候補として保持する。

> **後続能力へ寄与する状態は、単に保存されるだけでは足りず、後続計算の入力・参照・重み・参照集合・経路・計算量・形成更新のいずれかを実際に変化させる位置へ接続されている必要がある。**

状態: `能力作用横断候補`

これは「全ての高能力言語模型が明示中間状態再利用機構を持たなければならない」という普遍必要条件ではない。

## 6. 因果確認

能力寄与を確認するときは、可能なら次を行う。

```text
状態または作用を除去する
状態を固定する
状態を置換する
参照先を固定する
経路を固定する
作用を無効化する
↓
後続作用・参照・経路・結果の差を観測する
```

名称・設計文書・コード上の存在だけを能力寄与の十分証拠にしない。

## 7. MINIDORAへの扱い

MINIDORAの `保存状態数815 / 再利用0` は、保存機構の存在と後続利用の非同一を示す観測として使える。

ただし、これだけからGPQA低得点の単独原因を「再利用0」と断定しない。能力核の他経路、参照取得、候補表現、判断門等も同時に監査対象に残す。

MINIDORAでは、これらの能力作用を列挙・再現するだけでは能力主体として閉じず、HDSが別の判断主体として必要である。

このMINIDORA固有の役割分担を、LLM一般の普遍成立条件へ昇格しない。

## 8. 構文化との関係

本書は `NOTNN-LLM-MINIDORA/構文化/言語模型横断_日本語基底作用構文化_v3` の観測を構成定義側へ射影したものである。

構文化の個別方式観測をそのまま普遍要件へ昇格しない。構成定義側で分別した結果が構文化の観測単位を変える場合は、構文化側も再開放する。

## 9. 意思決定構造との境界

能力作用構成は、観測可能な局所作用と関係の記述である。

```text
局所作用群
≠
意思決定構造
≠
能力主体
```

何を目的とし、何を対象とし、どの状態を採用・棄却し、どこまで進行するかという判断原理は、本書の観測軸から自動的には導けない。

HDSはMINIDORAでこの判断を担う別主体であるが、HDS自体を本書で定義しない。

詳細は `08_構成定義の到達限界.md` に従う。

## 10. 再開放

新しい模型・実装・介入結果によって、ここでの観測単位自体が粗い、重複する、欠落する、または誤っていると分かった場合は、能力の定義・状態の定義・作用の定義から再開放する。

ただしHDSの改定やMINIDORAの性能変化だけでは、本書を再開放しない。
