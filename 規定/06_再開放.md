# 再開放

## 目的

現行規定を版内では固定しつつ、模型・言語・能力・境界・呼称の現在切り出しを絶対化しない。

## 1. 再開放原則

反例が出た場合、局所patchより先に「何を同じ対象としていたか」を戻して確認する。

## 2. 再開放条件

少なくとも次で再開放する。

- n-gram等の標準LMが現行定義で不合理に排除される。
- compiler / transducer / classifier等が後付け解釈だけでLMへ入る。
- 条件付き言語重み関係では記述できない、明確なlanguage model反例が出る。
- Masked Language Model / representation modelの境界が新証拠で変わる。
- 模型物 / 言語模型実行系 / 利用系の三境界でretrieval等を損失なく記述できない。
- 機能再現・能力再現・構造再現・因果機構再現の分離で扱えない反例が出る。
- 構成因果寄与 / 構成必要条件 / 構成不変量の分離が破綻する。
- Large / LLMの外部技術用例が変化する。
- MINIDORA等の下流失敗が、独立観測と照合して上位定義の欠落を示す。

## 3. 再開放順序

1. 対象・版の取り違え
2. 言語状態空間
3. 条件付き言語重み関係
4. 全体系列への接続
5. positive / negative control境界
6. 模型物 / 実行系 / 利用系
7. 能力分離
8. 再現種別
9. 因果寄与 / 必要性 / 不変量
10. 規模・現代LLM呼称
11. 規定全体

## 4. 変更履歴

改定時は旧版、新版、反例、独立根拠、変更対象、旧判定への影響を保存する。

## 5. 旧版

v3/v4/v5の観測・失敗・変更履歴は削除せず、現在版がなぜ変わったかの履歴証拠として保持する。

## 6. 現行版

現行版は **2026-08-28-成立規定-6**。

状態は **局所安定正本 / 再開放可** とする。
