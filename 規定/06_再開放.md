# 再開放

## 目的

現行規定を版内では固定しつつ、LM・能力・境界・呼称の切り出しを絶対化しない。

## 1. 再開放条件

少なくとも次で再開放する。

- n-gram等の標準LMが不合理に排除される。
- scoreだけの系が厳密LMへ入り込む。
- 正規化可能性を要求すると明確なLM反例を落とす。
- deterministic transducerとconditional LMの境界が新反例で崩れる。
- MLM / representation / global LMの境界が新証拠で変わる。
- 模型物 / 実行系 / 利用系でretrieval等を損失なく記述できない。
- 機能/能力/構造/因果機構再現の分離が破綻する。
- 因果寄与 / 必要性 / 不変量の分離が破綻する。
- Large / LLM外部用例が変化する。
- MINIDORA等の下流失敗が独立観測と照合して上位定義の欠落を示す。

## 2. 再開放順序

1. 対象・版
2. 完全言語状態空間
3. 確率法則 / 正規化可能性
4. local-to-global接続
5. conditional LM / transducer境界
6. MLM / scoring / representation境界
7. 模型物 / 実行系 / 利用系
8. 能力
9. 再現種別
10. 因果寄与 / 必要性 / 不変量
11. 規模・現代LLM呼称
12. 規定全体

## 3. 変更履歴

改定時は旧版、新版、反例、独立根拠、変更対象、旧判定への影響を保存する。

## 4. 旧版

v3〜v6の観測・失敗・変更履歴は削除しない。

## 5. 現行版

現行版は **2026-08-28-成立規定-7**。状態は **局所安定正本 / 再開放可**。
