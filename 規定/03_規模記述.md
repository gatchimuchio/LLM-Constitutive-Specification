# 規模記述

## 目的

厳密言語模型性と `Large` の呼称を分け、どの境界・尺度に対して大きいと述べるかを監査可能にする。

## 1. LM性と大規模性

```text
厳密LM性 != 大規模性
```

n-gram等の小規模LMはLMであり得る。巨大な外部databaseを使うだけの小さい処理系を自動的にLLMへしない。

## 2. 規模プロファイル

候補を `large` と記す前に、対象模型・版、比較集合、比較集合選定理由、採用尺度、測定境界、観測値、未観測尺度を固定する。

結果を見てから比較集合を事後選択してlargeを作ることを禁止する。

## 3. 模型物規模

parameter / active parameter、count / rule / graph要素数、artifact size、persistent formed state等。非ニューラル模型をparameter数へ無理に換算しない。

## 4. 形成規模

training / fitting / count estimation / distillation / compilation等に用いたdata、compute、corpus、反復。

## 5. 実行系規模

context、working state、固定retrieval index、runtime memory、compute等。

## 6. 利用系規模

任意Web、agent memory、tool ecosystem、multi-model system等。利用系巨大さを模型物規模へ無言加算しない。

## 7. 機能・能力規模

言語状態空間、文脈範囲、多言語/domain範囲、一般化範囲、能力範囲等。物理規模と同一ではない。

## 8. 現代LLM呼称との接続

現代LLMは歴史的に大規模なformed model artifact、training data、compute、language coverage等と結びついている。普遍一点閾値は置かないが、外部慣用から切断した独自largeを捏造しない。

## 9. MINIDORA

MINIDORAが厳密LM性または参照LLM機能等価を示しても、それだけでLargeは成立しない。規模プロファイルと呼称適合を別監査する。
