# 規模記述

## 目的

言語模型として何が成立しているかと、その模型をどの意味で「大規模」と呼ぶかを分ける。

v4までの固定三面 `状態域規模 / 関係域規模 / 共有適用規模` は有用な観測軸だったが、実在LLMで用いられる「large」の根拠を十分には表していないため、v5では普遍固定面から外し、**規模プロファイル**へ置き換える。

## 1. 言語模型性と規模を分ける

```text
言語模型性 != 大規模性
```

小規模でも言語模型は成立し得る。大きなデータベースや巨大な計算資源を持つだけで言語模型になるわけでもない。

## 2. 「大規模」は尺度宣言付きの相対記述

候補を大規模と記す場合、次を宣言する。

- 対象模型・版
- 比較集合
- 採用する規模尺度
- 各尺度の観測値または相対位置
- その尺度を採用する理由
- 未観測尺度

普遍的一点閾値を捏造しない。

## 3. 規模プロファイルの代表尺度

固定必須数は置かない。対象に応じて、少なくとも次から有効な尺度を選ぶ。

### 実現規模

現在模型物そのものの物理・記号的規模。

例:

- parameter数 / active parameter数
- 規則数
- 表・グラフ・索引の要素数
- persistent memory量
- model artifact size

### 形成規模

現在模型状態を形成するために用いた資源・資料の規模。

例:

- training / distillation / compilation data量
- formation compute
- corpus規模
- 反復回数

形成規模は形成履歴の尺度であり、現在模型物そのものと混同しない。

### 実行状態規模

一回または継続実行で扱える状態量。

例:

- context length
- recurrent / working state容量
- 同時保持状態数
- external indexが模型境界内の場合の参照可能状態量

### 言語状態域規模

対象言語体系において、模型が成立差を形成できる状態の種類・粒度・長さ・組合せの広さ。

### 構成再利用規模

同じ模型側作用を、どれほど多様な未列挙状態・文脈・組合せへ再利用できるか。

### 関係・作用域規模

文脈距離、依存階層、作用範囲、段階輸送、再作用可能域等、模型内部の関係・作用の広さ。

## 4. 旧三面の扱い

旧 `状態域規模 / 関係域規模 / 共有適用規模` は廃棄しない。

- 状態域規模 → `言語状態域規模` / `実行状態規模` の補助観測
- 関係域規模 → `関係・作用域規模` の補助観測
- 共有適用規模 → `構成再利用規模` の補助観測

として履歴互換的に読み替える。

ただし三面だけを「large」の完全定義にはしない。

## 5. 物理規模と機能規模を混同しない

巨大なparameter数・索引・データ量を持っていても、言語状態域や構成再利用が狭い場合がある。

逆に、物理規模が小さい模型でも広い言語状態域へ作用し得る。

したがって、

```text
物理規模 != 機能規模
```

として並記する。

## 6. 現代LLMという慣用との接続

現代の `large language model` という呼称は歴史的に大きなparameter数・training data・compute等と強く結びついている。一方、モデル方式がニューラル以外へ広がる場合、parameter数だけを普遍尺度にはできない。

そのため本規定は、外部慣用を無視して独自の「large」を作らず、**どの規模尺度に基づく呼称かを明示する**方式を採る。

## 7. 専門特化

専門領域へ特化していても、採用した規模尺度と比較集合に対して大きいと位置づけられる場合がある。

汎用性・多領域性を大規模性と同一視しない。

## 8. 狭い業務処理との境界

固定ラベル、少数テンプレート、固定FAQ等へ実質的に閉じる系は、巨大な物理データ量を持っていても、言語状態域・構成再利用規模では小さくなり得る。

## 9. 大規模言語模型という呼称

```text
言語模型性が成立
+
規模プロファイルを明示
+
比較集合に対して「large」と呼ぶ根拠を明示
→ 大規模言語模型という局所的な位置づけ
```

`large` を言語模型中核の隠れた第五条件へしない。
