# 規模記述

## 目的

言語模型機能と `Large` の呼称を分け、どの境界・尺度に対して大きいと述べるかを監査可能にする。

## 1. 言語模型性と大規模性

```text
言語模型機能成立 != 大規模性
```

n-gram等の小規模LMは言語模型であり得る。巨大な外部databaseを使うだけの小さい処理系を自動的にLarge Language Modelへしない。

## 2. 規模プロファイル

候補を `large` と記す前に次を固定する。

- 対象模型・版
- 比較集合
- 比較集合を選ぶ理由
- 採用尺度
- 模型物 / 実行系 / 利用系のどの境界を測るか
- 観測値または相対位置
- 未観測尺度

**結果を見てから比較集合を事後選択してlargeを作ることを禁止する。**

## 3. 模型物規模

現代LLM呼称では、まず言語模型物・形成済み模型状態の規模を中心に記録する。

例:

- parameter / active parameter
- count / rule / table / graph要素数
- model artifact size
- persistent formed state量

非ニューラルではparameter数へ強制変換しない。

## 4. 形成規模

training / fitting / count estimation / distillation / compilation等に用いたdata、compute、反復、corpus規模。

現在模型物の規模と形成履歴の規模を混同しない。

## 5. 実行系規模

一回または継続実行で必要なcontext、working state、fixed retrieval index、runtime memory、compute等。

実行系固定依存は重要だが、模型物規模とは別に記録する。

## 6. 利用系規模

任意Web、agent memory、tool ecosystem、multi-model system等の規模。

**利用外周の規模を無言で模型物規模・Large呼称へ加算しない。**

## 7. 機能規模

必要に応じて次を記録する。

- 言語状態空間の広さ
- 文脈範囲
- 多言語・domain範囲
- 未列挙組合せへの一般化範囲
- 能力範囲

機能規模は物理規模と同一ではない。

## 8. retrieval依存系

巨大corpusを固定参照する実行系では、

```text
模型物規模
実行系固定index / corpus規模
利用系外部情報規模
```

を分ける。

外部corpusが巨大であるだけでは、模型物自体をlargeとしない。逆に、現代用例がsystem全体を特定名称で扱う場合は、その呼称範囲を別途明示する。

## 9. 現代LLM呼称との接続

現代の `large language model` は歴史的に大規模なformed model artifact、training data、compute、language coverage等と結びついている。

普遍的一点閾値は置かないが、外部慣用から切断した独自largeを捏造しない。

## 10. MINIDORAへの境界

小規模MINIDORAが言語模型機能や参照LLMの機能等価を示しても、それだけで `Large` は証明されない。

Large呼称は規模プロファイルと現代LLM呼称適合を別監査する。
