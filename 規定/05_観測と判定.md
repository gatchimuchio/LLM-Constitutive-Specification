# 観測と判定

## 目的

言語模型機能、能力、規模、呼称、模型境界、再現種別を別々に監査する。

## 1. 対象を先に固定

候補結果を見る前に、対象模型・版、言語体系、言語状態空間、文脈、対象範囲、比較集合、監査時点を固定する。

## 2. 言語模型機能監査

最低限次を確認する。

1. 言語状態空間が明示される。
2. 模型自身の実行意味として条件付き言語重み関係が存在する。
3. 一意出力を事後的にデルタ分布へ読み替えていない。
4. 局所作用の場合、完全言語状態の重み・factorization・生成過程への接続を確認する。
5. 模型関係が入力ごとの外部正解注入ではなく持続模型状態へ属する。
6. 同一条件で関係が再確認できる。

## 3. positive control

### n-gram

文脈から次語へ条件付き確率を与え、chain rule/factorizationで系列へ接続する。表・count型であることを理由にLM一般から排除してはならない。

### causal LM

次token条件付き重みのfactorizationから完全系列へ接続する典型例。

### encoder-decoder conditional LM

source条件付きでtarget系列へ重みを与える模型として監査できる。

### diffusion / iterative LM

逐次token左→右でなくても、生成遷移が完全言語状態の分布・重みへ接続するなら成立形になり得る。

### weighted / probabilistic grammar

文字列・系列へ相対重みを与える場合、形式文法であることだけを理由に排除しない。

## 4. negative control

### compiler境界監査

compiler / deterministic transducerが一つのtargetを返すこと自体を、条件付き言語重み関係へ読み替えない。外部意味論の実行とlanguage modelingを分ける。

### classifier

タスクlabel scoreと、言語状態空間上の重みを分ける。

### parser / recognizer

accept/reject・parse tree生成だけなら形式言語認識として分ける。weighted language relationが別にある場合のみその部分をLM監査する。

### retriever only

既存record取得だけをLMとしない。

## 5. BERT / MLM監査

BERT encoder artifactとMLM pre-training systemを分ける。

Masked Language Modelがmasked位置の条件分布を与えても、完全系列のjoint distribution / coherent generative modelを自動的に定義するとは限らない。

したがって、

- encoder artifact: representation model監査。
- MLM objective/head: 局所言語模型作用監査。
- 完全系列LMへ導出した場合: 導出の整合性を含めてLM監査。

とする。

## 6. anti-posthoc監査

任意のdeterministic systemは数学上「出力へ1、それ以外へ0」と後付けできる。この操作を許すとcompiler、calculator、database queryまでLM化するため禁止する。

**言語重み関係は候補系の内部実行意味として先に存在しなければならない。**

## 7. 一般化能力監査

未列挙組合せ、置換、語順、条件、反実仮想等への一般化は重要な能力監査である。

ただしn-gram等のLM一般を落とさないよう、言語模型機能の普遍成立条件とは分離する。

## 8. 能力監査

推論、知識、GPQA、翻訳、長文、tool use等を言語模型機能とは別に測る。

MINIDORAのGPQA改善/悪化をLM性へ直接投影しない。

## 9. 模型境界監査

`04_運用境界.md` に従い模型物 / 実行系 / 利用系を分ける。

retrieval等は部品名で内外を決めない。

## 10. 構造再現監査

元模型で直接観測できた構造・接続・state配置等について忠実度を評価する。

構造が再現されたことから対象能力への因果必要性を導かない。

## 11. 因果機構再現監査

### 11.1 構成因果寄与

証拠強度を分ける。

- 強: direct intervention / ablation / disable / controlled substitution。
- 中: 十分に統制されたsame-family比較・自然実験。
- 弱: source code / design文書の意図と観測挙動の整合。

弱だけで因果寄与を確定しない。

### 11.2 構成必要条件

因果寄与より強い。単一ablationで性能低下しても必要とは限らない。

- 冗長経路
- 代替実装
- 機能同値物
- 補償作用

を宣言範囲で監査し、これらを除いても成立するなら「必要条件」としない。

### 11.3 構成不変量

宣言したrealization変更・比較範囲で保存される性質を確認する。因果寄与と別軸である。

## 12. 機能再現 / 能力再現

機能再現は条件付き言語重み関係の対応を比較する。能力再現は推論・知識等の対象能力を比較する。

同じ最終textだけで機能・能力・内部構成のすべてが再現されたとはしない。

## 13. 現代LLM呼称監査

言語模型機能成立とは別に、

- 模型物規模
- 形成規模
- 現代技術用例
- 比較対象
- 当該名称の射程

を確認する。

非ニューラル系について、`LLM機能等価` と `現代LLM呼称適合` を分ける。

## 14. 規模監査

比較集合を事後選択しない。模型物規模、実行系規模、利用系規模を分ける。

## 15. 下流失敗からの逆算

下流物の失敗を「実装が悪い」と先に固定しない。次のどこでも再開放できる。

1. 言語模型機能定義
2. negative / positive control境界
3. 模型物 / 実行系境界
4. 能力定義
5. 再現種別
6. 因果寄与 / 必要性 / 不変量
7. 規模・呼称

下流点数だけを正本変更の十分根拠にはしない。

## 16. 状態語

局所安定 / 不適合 / 未観測 / 未確定 / 矛盾 / 保留 / 対象外 / 再開放要を用いる。
