# 規定言語

## 目的

本規定体系では、日本語を表示上の優先言語ではなく、**対象を切り出し、差異を保持し、関係を分別し、定義し、判断し、監査し、再構成するための唯一の基底・規定言語**とする。

本規定は `gatchimuchio/cognitive-engineering-foundations` の現行認知工学体系、とくに `PUBLICATION_POLICY.md` と『情報工学における言語基底論』を最上位理論正本として参照する局所射影である。

- 最上位理論正本: `https://github.com/gatchimuchio/cognitive-engineering-foundations`
- 現行参照 commit: `60131da52ba7931ed7f82c7648a74ac790f50d08`
- 基底言語・規定言語: **日本語**

ここで「最上位」は一方向の固定上流下流を意味しない。新観測・実装結果・再分別により、本規定から認知工学側の前提まで再開放し得る。

## 基本原則

### 1. 日本語先行

新しい概念・区別・関係・状態・境界・禁止・採否・再開放条件を定めるときは、最初に日本語で意味を閉じる。

```text
日本語で対象化
→ 日本語で差異化
→ 日本語で関係化
→ 日本語で定義・構造化
→ 日本語で監査・改訂
→ 日本語正本成立
→ 実務上必要な場合だけ他言語へ射影
```

他言語の名称・略号・既存カテゴリを先に置き、その翻訳語として日本語を与える方法を正本規定では採用しない。

### 2. 日本語正本

定義、規定、境界、状態、採否、改訂理由、監査結果、再開放条件は日本語正本を優先する。

他言語版・他言語識別子・数式記号・外部方式名は日本語正本からの二次射影または参照札であり、それらから日本語正本の意味を逆定義しない。

### 3. 他言語は例外使用

英語その他の言語は、**実務上やむを得ない接続面に限って例外的に使用する。**

許容例:

1. 外部API・通信規約・標準規格が特定言語の識別子を要求する。
2. プログラミング言語、ライブラリ、型、構文等が特定表記を要求する。
3. 模型、製品、論文、組織、方式、規格等の固有名を正確に指す。
4. 原文引用、出典保存、検索再現のため原語を保持する。
5. ファイル形式、環境変数、CLI、CI等の機械接続上避けられない。
6. 国際公開や相互運用のため二次言語版を作る。
7. 既存技術語との対応関係を監査するため外部対照名を保持する。

「業界で普通だから」「既存論文が英語だから」「翻訳しやすいから」だけでは例外理由としない。

## 外部語の扱い

外部語は**意味正本ではなく対照名**として扱う。

例:

```text
厳密言語模型                     ← 日本語正本
外部対照名: strict language model

局所条件から完全法則への接続      ← 日本語正本
外部対照名: local-to-global connection

言語得点関係                     ← 日本語正本
外部対照名: scorer / score relation
```

外部対照名を削除しても日本語だけで意味が再構成できなければ、正本化不足とする。

## 禁止事項

- 英語名を先に作り、日本語訳を後から正本と称する。
- 外部APIの語彙粒度を内部概念の粒度へそのまま写す。
- `model`、`core`、`layer`、`runtime`、`profile`、`state`、`routing` 等の一般語義から日本語側の境界を暗黙に導く。
- 外部方式名をそのまま構成要件へ昇格する。
- 翻訳しやすさを理由に、日本語で保持できる関係差を削る。
- 機械実装の都合を理由に、日本語正本の意味構造を外部スキーマへ従属させる。
- 他言語に一語対応がないという理由で、日本語側の概念を捨てる。
- 一度付けた外来名称を対象本体の恒久構造とみなす。

## 機械識別子

コード・JSON・API等で他言語識別子を使う場合、識別子は日本語定義への参照札とする。

```text
外部・機械識別子
    ↓
日本語正本の参照位置
    ↓
日本語で定義された意味
```

機械識別子の綴りや一般語義を正本意味へ逆流させない。

可能な実装環境では、日本語識別子・日本語コメント・日本語ファイル名を優先する。

## 固有名

Llama 3、Kimi K3、Transformer、Attention、Python、JSON、n-gram等は固有名・方式名・外部名として原表記を保持できる。

固有名が存在することを理由に、その語を基底概念へ昇格しない。

## 正本化前監査

正本候補は次を満たすまで確定しない。

1. 他言語を削除しても日本語だけで意味が閉じる。
2. 外部略号を別名へ置換しても対象・関係・境界が変わらない。
3. 外部カテゴリを日本語カテゴリへ直写していない。
4. 日本語側にしかない意味差を翻訳時に残差として保持できる。
5. 日本語規定語が他言語一般語義を暗黙参照しなくても再構成できる。
6. 他言語使用箇所に実務上の必要性がある。
7. 新観測によって日本語側の切り出し自体を再監査できる。

## 自己適用

本規定言語規則も監査対象から除外しない。

日本語基底が現在の目的・対象・意味構造保持要求に適合しなくなる具体的観測が得られた場合は、言語だけを差し替えず、何を意味・差異・関係・損失とみなしたかまで再開放する。
