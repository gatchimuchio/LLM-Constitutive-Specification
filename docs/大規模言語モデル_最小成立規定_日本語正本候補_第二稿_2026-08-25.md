# 大規模言語モデル 最小成立規定（仮）

## 日本語正本候補・第二稿

状態: **正本候補 / 未確定 / 再開放可**

日付: 2026-08-25

外部互換呼称: Layer-0 / LLM Layer-0

> 外部互換呼称は二次名称である。本書の意味は日本語本文を正本とする。

---

# 0. 目的

本書は、2026年8月時点で実在する異種の大規模言語モデル群をHDSで再観測し、特定の実装方式・形成方式・ベンダー用語を前提にせず、次を最小限に規定する。

1. 何を言語モデル成立と呼ぶか。
2. 何を大規模資格と呼ぶか。
3. どこまでをモデル同一性として扱うか。
4. 何がモデル中核で、何が運用・形成・利用外周か。
5. 何を観測すれば成立・不成立・保留を分けられるか。

本書は物理部品数を最小化しない。

> **最小とは、必要な区別・関係・境界を一つ外したとき、同じ意味で成立判定を閉じられなくなる局所境界である。**

---

# 1. 上位原則

## 1.1 総暫定性

本書の、

- 言語モデル
- 大規模
- 状態
- 文脈
- 形成
- モデル
- 同一性
- 境界
- 観測

という切り出し自体も、2026-08-25時点の有限Projectionである。

版内では強く固定するが、将来の再開放を禁止しない。

## 1.2 非同一

```text

模型物 ≠ 言語モデル性そのもの
模型形成関係 ≠ 単発外部出力

```

を保持する。

## 1.3 循環禁止

MINIDORAおよび現行HDS Compilerは旧Layer-0から派生したため、新規定の成立証人にしない。

新規定確定後にゼロから再監査する。

# 3. 言語モデル成立の三つの必要区別

言語モデル成立を、三つの物理componentではなく、次の三つの意味区別で閉じる。

## 3.1 対象言語関係

> **対象言語関係とは、本版で対象化した自然言語状態の間に、モデル化対象として切り出した関係である。**

現代生成LLM群の中心対象として、

> **文脈付き言語状態と、未提示・未確定の言語状態の成り立ちとの関係**

を置く。

これは自然言語全体そのものではない。

## 3.2 模型形成関係

> **模型形成関係とは、モデル内部で再利用され、文脈付き内部言語状態に応じて、未提示・未確定の言語状態に関する言語形成状態を生じさせる関係である。**

実装方式は固定しない。

## 3.3 対応確認

> **対応確認とは、模型形成関係による状態差が、宣言した対象言語関係の差と対応していることを、観測範囲内で確認することである。**

random mappingやhash等は、型が同じでも対象言語関係へ対応しなければ成立しない。

---

# 4. 言語形成状態

## 4.1 定義

> **言語形成状態とは、模型形成関係の結果として生じ、未提示・未確定の言語状態について、その成り立ちを区別・制約・確定するための差を含む内部結果状態である。**

## 4.2 普遍形式を固定しない

言語形成状態は、

- logits
- score
- probability
- ordering
- candidate set
- constraint
- singleton
- deterministic next state
- denoising proposal

等として実装され得る。

どれか一つを普遍必須にしない。

## 4.3 確率分布を必須にしない

Qwen系、DeepSeek V4、Kimi K3等では、モデルforwardがsoftmax前scoreを返す経路を観測できる。

LLaDAでも、model logits形成後にsampling・confidence・remasking等の生成作用が接続される。

従って、確率分布・samplingは許容されるが、中核普遍形式とはしない。

---

# 5. 文脈依存

主対象8系統では、文脈差が言語形成状態へ作用することに射程内反例がない。

従って本版では、

> **文脈依存**

を言語モデル成立関係の条件面として保持する。

ただし、

- Attention
- KV cache
- recurrent state
- sliding window
- compressed state

等の特定方式は必須にしない。

LLaDA追加により、左から右・1token逐次・自己回帰next-tokenだけに固定しない。

---

# 6. 言語住所規約

## 6.1 定義

> **言語住所規約とは、外部自然言語状態と、モデル内部で参照される位置・記号・状態との対応関係である。**

実装例はtokenizer、vocabulary、byte mapping、special token等。

名称を必須にしない。

## 6.2 位置づけ

言語住所規約は第4の模型componentではない。

対象言語関係と模型形成関係を対応づけ、モデルの言語関係同一性を定める境界契約として扱う。

---

# 7. モデル同一性

モデル同一性を一つへ潰さない。

## 7.1 物理同一性

weight、rule、table、graph、code、hash等の再現上の同一性。

## 7.2 言語関係同一性

言語住所規約と模型形成関係が、外部自然言語に対して同じ関係を保持する同一性。

正本の中心はこれ。

## 7.3 運用同一性

sampling、停止条件、chat formatting等を含む実行挙動上の同一性。

モデル中核同一性とは分ける。

---

# 8. 大規模資格

## 8.1 言語モデル成立と分離

```text
言語モデル成立
×
大規模資格
=
大規模言語モデル
```

大規模は別runtime作用ではない。

## 8.2 大規模性と汎用性を分離

BloombergGPT、BioGPT、Code Llama等の領域特化モデルが存在するため、

```text
大規模 = 多領域汎用
```

とはしない。

汎用性は別能力軸とする。

## 8.3 三観測面

### 状態域規模

対象領域で扱える言語状態の種類・粒度・長さ・組合せ。

### 関係域規模

対象領域で扱える文脈・依存・照応・形成等のrelationの種類・距離・階層。

### 共有適用規模

同一言語関係同一性を、対象領域内のどれだけ多数の異なる状態・文脈・組合せへ共有適用できるか。

## 8.4 一点閾値なし

普遍的一点のparameter数等をLarge境界へ置かない。

物理規模値は実装別証拠として記録する。

---

# 9. 表・検索・規則の扱い

表、DB、rule、graph等の実装名だけで排除しない。

区別するのは、

- 保存済み完成個体を取得しているだけか
- 文脈付き言語状態から言語形成状態を与える模型形成relationを保持しているか

である。

形成relation全体を表で保持する実装を、表だからという理由だけで排除しない。

---

# 10. モデル中核と表出作用

## 10.1 モデル中核

```text
文脈付き内部言語状態
→ 模型形成関係
→ 言語形成状態
```

## 10.2 表出作用

> **表出作用とは、言語形成状態を用いて、外部へ接続する結果言語状態を確定・反復形成する作用である。**

argmax、sampling、top-p、beam、denoising update等が実装例。

## 10.3 分離

```text
模型形成関係の結果
!=
単発の外部言語結果
```

を維持する。

ただし、物理実装で両者が統合されることは許容する。

---

# 11. 運用閉包

運用型生成LLMとしては、

```text
外部言語入力
→ 言語住所接続
→ 文脈付き内部言語状態
→ 模型形成関係
→ 言語形成状態
→ 表出作用 / 反復
→ 外部言語結果
```

を確認する。

この閉路全体をモデル中核と同一視しない。

# 14. 証拠状態

模型物の存在と、言語モデル機能を分ける。

最低限、次を別に記録する候補とする。

1. **模型物確認** — artifact等を観測できる。
2. **言語形成機能観測** — 外部挙動で形成機能を観測できる。
3. **言語形成関係成立** — 対象言語relationと模型relationの対応が確認される。
4. **運用閉包成立** — 外部入力から外部言語結果まで実行閉路が閉じる。
5. **大規模資格** — 規模profile。

各項目に、成立 / 不成立 / 保留 / 未観測 / 対象外を持つ。

状態数は第三稿で再圧縮する。

---

# 15. 旧Layer-0六構成の再配置

| 旧観測 | 第二稿での位置 |
|---|---|
| token / symbol space | 言語住所規約・言語同一性境界 |
| context state | 模型形成関係の条件側 |
| transform | 模型形成関係の実装作用 |
| learned / parameterized | 形成過程・artifact形式 |
| conditional linguistic output | 言語形成状態 |
| fitting objective | 形成過程 |
| decoding / emission | 表出作用・運用閉包 |

旧観測を削除せず、帰属階層を訂正する。

---

# 16. 現時点の最短定義候補

> **大規模言語モデルとは、定めた自然言語対象域において、対象言語関係に対応する文脈依存の模型形成関係を大規模な状態・関係範囲へ適用し、未提示・未確定の言語状態について言語形成状態を生じさせるモデルである。**

この一文だけでは、同一性・大規模性・対応確認の細則は閉じないため、本書全体を規定とする。
