# Official LLM Reference Bundle — Legacy Context

この文書に記録されていたprovider用例はv3の用語境界アンカーであった。v4では、providerがあるmodel familyをLLMと呼ぶ事実は**taxonomy / public-usage evidence**としてのみ扱い、Functional Coreの普遍必要性をそこから導出しない。

v3当時の引用・URL・witnessは生成artifactとgit履歴に保存されている。現行mainのFunctional Core合否はprovider呼称ではなくcandidate execution evidenceで判定する。
