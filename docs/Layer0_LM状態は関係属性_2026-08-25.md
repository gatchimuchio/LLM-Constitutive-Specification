# Layer-0 LM状態は関係属性 — 2026-08-25

## 状態

`WORKING / NOT_CANONICAL / REOPENABLE`

本書は、Language Modelという分類をartifact内部の固定属性として扱わず、対象Projection・artifact・観測対応の関係として扱う。

---

# 1. T/M/Cの非対称

前段では、

```text
T 言語対象契約
M 有限モデル射影
C 言語モデル適合
```

を分けた。

ここで重要なのは、三者が同じ存在階層ではないことである。

## T

評価者・設計者が現在どのlanguage scope / target relationを対象化しているかという**Target Projection契約**。

artifact内部に明示保存されていなくてもよい。

## M

実際のmodel artifact。

- weights
- rules
- tables
- graph
- program
- compiled relations

等。

## C

TとMの対応について得られた**Observation / Evidence**。

artifact内部componentではない。

---

# 2. Language Model statusの再定義

従って、

```text
LM = artifact Mの固定内在属性
```

とは扱わない。

より正確には、

> **あるartifact Mが、現在対象化した言語Target Projection Tに対して、観測Cの範囲でLanguage Modelとして適合している。**

という関係上の判定である。

同じartifactでもtarget scopeを変えれば判定が変わり得る。

---

# 3. マルチモーダルmodelへの適用

一つのmultimodal artifactが、

- vision relation
- audio relation
- language relation
- cross-modal relation

を同時に持ち得る。

whole artifactへ単一ラベルを貼るより、

```text
artifact M
  ├─ T_language  -> C_language
  ├─ T_vision    -> C_vision
  └─ T_cross     -> C_cross
```

と分ける。

`M is LM`ではなく、

```text
M conforms as LM under T_language
```

と扱う。

---

# 4. classifier / encoderへの適用

同じartifact/system内に、

- encoder language relation
- task classifier relation

が共存し得る。

language target sliceではLM適合、task-label target sliceではclassifier適合という複数分類を許容する。

system全体を一語へ潰さない。

---

# 5. MINIDORAへの適用

MINIDORAについても、

```text
MINIDORA = LLM
```

を先に固定しない。

代わりに、

1. language target relationを対象化
2. そのrelationを担うartifact範囲を切る
3. conformance evidenceを取る
4. Large profileを測る

という順序で判定する。

もしlanguage target relationがCompilerにしか存在せず、中央K/C/Jはworld/task relationのみなら、

- Compiler slice = language model candidate
- central reasoning slice = semantic reasoning engine
- whole system = language-mediated reasoning system

等へ分解され得る。

逆に、中央までlanguage relationが一貫して存在するならwhole artifactのLM conformanceを支持できる。

---

# 6. Artifact identityとclassificationを分ける

## Artifact identity

```text
artifact_id
version
implementation/provenance
relation-bearing structures
```

## Classification

```text
target_projection
scope
observations/evidence
conformance_state
```

を別にする。

これにより、新観測でclassificationが変わってもartifact過去版のidentityを無言上書きしない。

---

# 7. Largeも関係属性

Largeもartifactのparameter数だけでは決まらない。

T_languageに対して、

- 状態域幅
- 関係域幅
- 再利用域幅

がどれだけ広いかというprofileである。

別targetではLarge profileが異なる場合を許容する。

---

# 8. 現時点の判定

- T/Cをmodel artifact componentとして数える: **否定**
- LM statusをM単体の絶対属性とする: **否定**
- LM statusをT-M-C関係上の適合状態とする: **強く支持**
- multimodal/compound systemを単一カテゴリへ潰す: **否定**
- artifact identityとclassificationの分離: **必須**
- MINIDORAを自己定義でLMへ固定: **禁止**

v5正本候補では、Layer-0を「component minimum」より**対象・モデル・適合・実行の最小契約**として再記述する。
