# 大規模言語モデル 最小成立規定（仮）

**日本語正本候補・第一稿**

状態: 正本候補 / 未確定 / 再開放可

日付: 2026-08-25

外部互換呼称: Layer-0 / LLM Layer-0

> 外部互換呼称は二次名称である。本書の定義・規定・採否・改訂は日本語本文を正本とする。

---

## 0. 本書の目的

本書の目的は、2026年8月時点で実在し「大規模言語モデル」と呼ばれている複数の異質なモデル群を、HDSによって日本語で再観測し、特定の実装方式・学習方式・英語圏の既存分類を前提にせず、次を最小限に規定することである。

1. 何を大規模言語モデルの原対象とするか。
2. 何が成立すれば大規模言語モデルと呼べるか。
3. どこまでをモデル本体として扱い、どこからを外部へ分けるか。
4. どの作用が普遍で、どの作用が個別実装・効率化・形成過程にすぎないか。
5. 「大規模」が何を意味するか。
6. 何を観測すれば成立・不成立・保留を判定できるか。

本書は、部品数を先に決めない。

本書は、ニューラルネットワーク、Transformer、Attention、自己回帰、確率分布、学習済み重み、パラメータ数、次語予測、復号器、API、チャットUI、エージェント機構のいずれも、名称だけで普遍必須条件へ置かない。

同時に、それらを先験的に不要とも断定しない。

## 1. 上位境界

### 1.1 総暫定性

本規定で用いる、

- 大規模言語モデル
- 言語
- モデル
- 状態
- 文脈
- 作用
- 機能
- 境界
- 大規模性
- 観測
- 成立
- 最小

という切り出し自体を、認知以前の絶対実体として扱わない。

これらは本版で作業・監査・再構成を可能にするための時間付き暫定規定である。

版内では強く固定するが、新観測による将来の再開放を禁止しない。

### 1.2 対象と記述の非同一

本書に書かれた定義は、大規模言語モデルという対象そのものではない。

```text
対象 ≠ 記述
実物 ≠ HDS構文化物
言語状態 ≠ その表現形式
モデル作用 ≠ その実装名
```

を版内境界として保持する。

### 1.3 循環禁止

MINIDORAおよび現行HDS Compilerは、旧Layer-0を前提として構成された下流物である。

したがって、新規定の成立証人として使用しない。

新規定は、独立した実在大規模言語モデル群の観測から閉じる。

新規定が閉じた後に、MINIDORA、HDS Compiler、その他の派生実装をゼロから再監査する。

## 2. 原対象

本版の原対象は、**人間の自然言語を広域に扱う、実在の大規模言語モデル群**とする。

主観測対象は、少なくとも次を含む。

- Llama 3
- K2-V2
- OLMo 3
- Apertus 1.5
- Qwen3.6
- DeepSeek V4
- Kimi K3

閉鎖モデル群は、公開された機能・外周境界のみを補助観測する。内部構造を推測して埋めない。

### 2.1 原対象へ含めないもの

次を、名称だけで大規模言語モデル本体へ含めない。

- 製品UI
- エージェント反復
- 検索サービス
- 外部道具
- 安全分類器
- 承認機構
- 配備時の振分け
- 分散実行基盤
- 単なる保存データベース

ただし、候補モデルの成立に不可分であることが観測された場合は、境界を再開放する。

### 2.2 派生対象

次は本版の原対象ではなく、原対象の規定が閉じた後に派生適用として扱う。

- プログラム言語
- 数式・形式言語
- 音声中心モデル
- 画像中心モデル
- マルチモーダル全体
- エージェントシステム

マルチモーダルモデルを観測する場合、本版ではまず自然言語を扱う部分関係を切り出す。

## 3. 日本語規定語

### 3.1 言語状態

本書でいう**言語状態**とは、原対象である人間の自然言語について、ある時点・範囲・文脈で区別可能になっている表現状態である。

言語状態は、文字列に限定しない。

実装上は、例えば、

- 文字
- 語
- token列
- ID列
- 内部表現
- 隠れ状態
- 再帰状態
- 構造化された関係表現

等へ射影され得る。

ただし、これらの実装形式自体を言語状態の普遍定義にはしない。

### 3.2 文脈

本書でいう**文脈**とは、現在の言語状態について、候補・解釈・復元・継続・変換の結果差へ作用し得る、既出または併置された状態・関係・条件である。

文脈は長文履歴に限定しない。

局所語順、前後関係、会話履歴、入力条件、役割境界、他媒体から接続された条件等を含み得る。

### 3.3 未提示言語状態

本書でいう**未提示言語状態**とは、入力としてそのまま完成形を与えられていないが、現在の言語状態と文脈から、モデルが候補・評価・復元・継続・変換の対象として形成する言語状態である。

例:

- 続く語・文字・区間
- 欠損部分
- 書き換え後の表現
- 翻訳先表現
- 複数候補の言語適合評価

外部へ文字列として出力される必要はない。

### 3.4 モデル同一性

本書でいう**モデル同一性**とは、入力ごとに別の専用処理系へ交換するのではなく、同一版として扱うモデル関係が、複数の異なる言語状態・文脈へ再利用されることをいう。

物理重みが同じことだけを同一性としない。

版、設定、適用規則、必要な実行条件を含む現在の境界で同一性を記録する。

### 3.5 最小

本書でいう**最小**とは、部品名や責任名の個数が少ないことではない。

> その区別・関係・境界規則を一つ外したとき、同じ意味で大規模言語モデル成立を閉じられなくなる局所境界をいう。

別の場所へ暗黙に移しただけの場合は、除去とみなさない。

## 4. 最小閉包

大規模言語モデルの成立を、本版では次の三つで閉じる。

### 4.1 対象

何を一つの候補モデルとして扱うかを固定する。

最低限、次を記録する。

- 候補名
- 版・時点
- 自然言語を扱う範囲
- モデル本体の観測可能境界
- 実行器との境界
- 外部サービスとの境界
- 観測できない範囲

対象が定まらない場合、成立判定を行わない。

### 4.2 成立関係

本版で最有力の中核関係は次である。

> **既知の言語状態と文脈を受け、同一モデル関係を再利用して、未提示の言語状態について候補・評価・復元・継続・変換を形成する。**

簡略形:

```text
既知の言語状態 + 文脈
        ↓
   同一モデル関係
        ↓
未提示言語状態の
候補 / 評価 / 復元 / 継続 / 変換
```

ここで重要なのは、最終文字列の出力ではなく、**未提示の言語状態を現在文脈から形成できること**である。

このため、自己回帰次語生成だけに限定しない。

一方、言語を単なる入口として、算術値、固定分類ラベル、保存済み個体、外部検索結果だけを返す系は、この関係だけでは成立しない。

### 4.3 閉包規則

成立関係をどう読むかを次で固定する。

#### 規則1　文脈差が効く

原対象である大規模言語モデルでは、少なくとも一部の言語状態について、文脈を変えると形成される候補・評価・復元・継続・変換が変わらなければならない。

文脈の物理保持方式は規定しない。

#### 規則2　言語状態そのものが結果対象である

結果は、未提示の言語状態またはその候補・適合評価へ接続しなければならない。

感情ラベル、画像分類ラベル、算術値など、言語外の固定結果だけへ閉じる場合は、本規定の中核関係には達しない。

#### 規則3　同一モデル関係が再利用される

入力ごと、話題ごと、言い回しごとに専用処理系へ交換せず、同一モデル同一性のもとで広い言語状態へ関係を再利用できなければならない。

#### 規則4　完全一致検索だけで閉じない

入力全体と出力全体の保存済み一対一対応を返すだけでは、中核関係の成立証拠としない。

ただし、表参照・検索・規則利用そのものを禁止しない。

現在文脈から、未提示の言語状態の候補・評価を形成するために再利用されているなら、実装名だけで除外しない。

#### 規則5　構成方法を成立条件にしない

学習、後学習、手書き、コンパイル、探索、蒸留、規則記述等は形成過程であり、成立関係そのものとは分離する。

#### 規則6　実装名を成立条件にしない

Attention、MoE、Dense、再帰、状態空間、グラフ、規則、表、ニューラルネットワーク等は、観測された実装形態として記録する。

名称だけで必須・禁止を決めない。

#### 規則7　外周を能力へ逆流させない

道具、検索、長期記憶サービス、安全分類器、エージェント反復、UI等の機能を、モデル本体の言語形成能力へ自動帰属しない。

## 5. 「大規模」の規定

ここまでの成立関係だけなら、狭い言語モデルも含み得る。

本版でいう**大規模**は、パラメータ数そのものではなく、同一モデル関係の適用範囲の広さとして扱う。

最低限、次の三方向を分けて記録する。

### 5.1 状態域の広がり

どれだけ広い自然言語状態を同じモデル同一性のもとで受理・形成できるか。

### 5.2 関係域の広がり

どれだけ多様な語順、依存、照応、文脈、継続、復元、変換等の言語関係を同じモデル関係で扱えるか。

### 5.3 再利用域の広がり

未列挙の表現組合せ、異なる話題、異なる文脈へ、同一モデル関係をどこまで差替えなしで再利用できるか。

### 5.4 一点閾値を置かない

「何パラメータ以上」「何語彙以上」「何トークン以上」で普遍的に大規模とする一点閾値は、本版では置かない。

大規模性は、観測対象群との相対位置と三方向の広がりとして記録する。

ただし、固定ラベル・有限テンプレート・単一業務処理へ実質的に閉じる系を、語義上の「大規模」だけで大規模言語モデルへ昇格させない。

## 6. 機能・作用・境界の分離

### 6.1 機能

本版の中核機能は、

> **現在の言語状態と文脈から、未提示の言語状態を形成可能にすること**

である。

形成には、候補化、評価、復元、継続、変換を含む。

### 6.2 作用

作用は、中核機能を実現する局所的な状態変化である。

例えば、

- 参照
- 混合
- 更新
- 比較
- 選択
- 差分反映
- 復元
- 反復

等があり得る。

ただし、この一覧を普遍作用集合へ固定しない。

個別モデルで観測された作用を、そのまま全大規模言語モデルの必須作用へ昇格しない。

### 6.3 境界

最低限、次を別に記録する。

- モデル本体
- 入力接続
- 実行器
- 出力表面
- 外部知識
- 検索
- 道具
- 安全系
- エージェント機構
- 形成過程

物理配置ではなく、成立関係へ何が寄与しているかで境界を読む。

## 7. モデル本体と実行可能系

モデル本体と実行可能系を同一視しない。

### 7.1 モデル本体

版として同定され、複数の言語状態・文脈へ再利用される関係を保持する成立物。

重み、規則、表、グラフ、プログラム、混成物等として実装され得る。

### 7.2 実行可能系

モデル本体を現在の入力状態へ適用し、結果状態を形成できる系。

```text
現在の言語状態
→ モデル関係の適用
→ 結果状態
```

実行器、入出力接続、計算資源が必要でも、それらを自動的にモデル本体へ含めない。

### 7.3 静的成立物

重みや規則等が保存されているが現在実行できない場合、モデル本体としての構造証拠と、実行可能性を分けて記録する。

## 8. 観測と判定

### 8.1 観測強度を分ける

本版では、少なくとも次を同一証拠として扱わない。

- 重み・設定・実装・実行を直接確認した観測
- 公開設定・実装を直接確認した観測
- 開発元文書と公開挙動の観測
- 製品挙動だけの観測

同じ日本語HDS語彙へ写ったこと自体を独立証拠としない。

### 8.2 成立

次が現在の観測範囲で閉じる場合、成立候補とする。

1. 原対象・版・境界が特定されている。
2. 既知言語状態と文脈から未提示言語状態を形成する関係が確認できる。
3. 文脈差が結果差へ到達する。
4. 同一モデル関係が複数の異なる言語状態へ再利用される。
5. 完全一致検索だけでは説明できない再利用が確認できる。
6. 大規模性の三方向が狭い単一用途へ閉じていない。

### 8.3 不成立

上記の成立関係を欠くことが観測できた場合、不成立とする。

### 8.4 保留

内部非公開、対象境界不明、観測不足、版不明、外部機構との寄与分離不能等により結論が分岐する場合、保留とする。

保留を推測で埋めない。

### 8.5 対象外

本版の原対象である人間自然言語の大規模言語モデルを直接扱っていない場合、対象外とする。

## 9. 反例境界

### 9.1 自然言語電卓

自然言語を解釈して算術値を返すだけなら、結果対象は主に算術状態であり、本版の中核関係を満たさない。

### 9.2 感情分類器

自然言語から固定ラベルを返すだけなら、未提示言語状態の広域形成を中核としない。

### 9.3 完全一致検索

保存済み入力に対応する保存済み文章を返すだけなら、同一モデル関係による未提示言語状態形成の証拠としない。

### 9.4 構文解析器

構文関係を扱うため言語処理系ではあるが、結果が構文木・固定構造表現だけへ閉じ、未提示言語状態の候補・評価・復元・継続・変換を形成しない場合、本版の大規模言語モデル中核から外れる。

### 9.5 n-gram

n-gramは狭い言語モデルとして成立し得る。

しかし本版の原対象は大規模言語モデルであるため、文脈依存の広がり、関係域、再利用域を別途満たす必要がある。

unigramを根拠に、大規模言語モデルから文脈依存を除去しない。

### 9.6 BERT型欠損復元

欠損した言語状態を文脈から候補・評価するため、中核関係の一例になり得る。

外部自由文生成がないことだけでは除外しない。

### 9.7 拡散型言語モデル

欠損・雑音化された言語状態を反復更新して復元する系が成立するなら、自己回帰、左から右、次語予測を普遍必須条件へできない。

## 10. 実在群への第一再写像

### Llama 3

公開HDS構文化では、既出token列から内部変換を経て語彙候補を形成し、次tokenを追加する経路が観測されている。

本版の中核関係へ自然に写る。

### OLMo 3

因果型言語生成モデルとして、長文脈・会話・推論等へ同一モデルを再利用する。

局所窓と全体参照の配置差は個別実装として保持する。

### Qwen3.6

条件付き生成を行うモデルとして、自然言語入力から生成状態を形成する。

linear/full attention周期やMoEは、成立関係そのものではなく実装差として保持する。

### DeepSeek V4

因果型言語モデルとして生成状態を形成する。

sliding / CSA / HCA、mHC、MoEは、系列・深さ・幅方向の個別計算構造として保持する。

### Kimi K3

Conditional Generation / Causal LMとして公開され、長文脈の言語入力を条件に生成を行う。

KDA / MLA / AttnRes / LatentMoE等は、成立関係を実現する個別構造として保持する。

### 共通観測

上記の構造差を越えて、少なくとも現行観測集合では、

```text
広い言語状態
+
文脈
→
同一モデル関係
→
未提示言語状態の形成
```

が反復して観測される。

これを現時点の中核候補とする。

## 12. 日本語正本規則

### 12.1 日本語を一次規定とする

定義・境界・判定・禁止・保留・改訂理由は日本語で閉じる。

英語その他の言語版は日本語正本からの二次射影とする。

### 12.2 英語識別子を主骨格にしない

Target / Model / Core / Conformance / Profile / Runtime / Wrapper 等の英語語彙を、日本語本文の定義骨格として使用しない。

必要な外部互換対応は別表へ分離する。

### 12.3 規定語

正本で用いる状態語は、原則として次とする。

- 成立
- 不成立
- 保留
- 対象外
- 未観測
- 未確定
- 矛盾
- 再開放

PASS / FAIL / SUSPEND 等は外部互換表示へ降格する。

### 12.4 無言翻訳禁止

日本語正本の語義を英語由来の一般的な意味へ無言で置き換えない。

「モデル」「文脈」「生成」「大規模」「最小」等は、本書で規定した意味を優先する。

## 13. 旧Layer-0への現在判定

旧Layer-0が観測した、

- 記号化
- 文脈利用
- 内部変換
- 条件付き結果形成
- 学習
- 復号
- 検索
- 知識保持
- 有効計算深度

等の観測を全て捨てるわけではない。

問題は、それらを同じ階層の「LLM成立条件」へ置いたことにある。

現時点では、

- 記号化・入力接続 → 接続実装
- 文脈利用 → 中核成立関係の一部
- 内部変換 → 個別作用
- 条件付き結果形成 → 中核成立関係の結果側
- 学習 → 形成過程
