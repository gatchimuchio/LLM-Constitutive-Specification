# Archival / Release Policy

- Tagged releases are immutable historical claim surfaces.
- v3.0 remains archived as the legacy six-role theorem package.
- Current main is `v4.0-provisional` until a new reviewed release is cut.
- A v4 release must run `make test-all` on a clean checkout.
- Release metadata and `CITATION.cff` must match the tagged version/date.
- Historical DOI references must not be presented as proof of current v4 claims.
