# 3. 現在の最小定義候補

## Language Model

> **ある有限model artifact Mが、現在対象化した言語Target Projection Tに対して、観測Cの範囲で言語relationを再現・利用するmodelとして適合している状態。**

より短く:

> **言語対象relationに対する有限model Projection。**

ただし`model = target`とは扱わない。

---

# 4. Language relation境界

LM CoreのTには少なくとも一つの**内在言語relation**を要求する方向。

例:

- sequence
- conditional candidate
- grammar/syntax
- reconstruction
- contextual representation
- language semantic relation

除外方向:

- pure arithmetic relation
- pure task-label relation
- pure world-fact identity mapping
- pure image->text mapping

言語I/OだけではLMにならない。

D3/D4 HDS観測anchorから強く再現する特徴:

- strong context dependence
- broad state domain
- broad/deep relation processing
- high effective compute depth
- broad reuse
- generative capabilityが運用中心

これを普遍原理へ昇格しない。

---

# 7. Adapter / Model / Lowering

現在の重要分離:

```text
Adapter
  representation connection

Modeling
  target relation interpretation / formation

Lowering
  rich state -> target-native compute state
```

現行HDS CompilerはModelingとLoweringを同じCompiler系列へ抱えている可能性が高い。

今回の性能低下の主要仮説:

```text
semantic richness
が
compute operand richness
へ誤伝播した
```
