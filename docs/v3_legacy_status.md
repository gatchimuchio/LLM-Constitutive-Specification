# v3 Legacy Status

The v3.0 six-role model, Layer A 64-subset enumeration, generated artifacts, and tagged release are retained for reproducibility and research history.

Current-main classification:

- six-role vocabulary: `LEGACY_LOCAL_MECHANISM / AUDIT_VOCABULARY`
- Layer A: `DECLARED_GRAPH_INTERNAL_CERTIFICATE`
- known-family mapping: `PUBLIC_WITNESS_MAPPING`
- universal/unique minimum claim for all contemporary LLMs: `WITHDRAWN_FROM_CURRENT_CLAIMS`

The v3 domain already incorporated learned parameterized transformation, sequence fitting, and operational emission. The resulting implication is valid within that domain, but it is not an independent proof that every real-world system ordinarily called an LLM must satisfy the same decomposition.

The v3 release remains unchanged. v4 establishes a new claim boundary on current main.
