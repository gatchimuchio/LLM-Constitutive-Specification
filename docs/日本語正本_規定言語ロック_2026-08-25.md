# 日本語正本 — 規定言語ロック

状態: 正本候補 / 未確定 / 再開放可

日付: 2026-08-25

---

## 0. 目的

「日本語で書いてある」ことと「日本語が規定言語である」ことを分ける。

旧Layer-0および再定義初期草案では、日本語本文の内部骨格を、

- Core
- Model
- Target
- Conformance
- Profile
- Runtime
- Wrapper

等の英語概念が事実上支配する箇所が残った。

本書はこれを禁止する。

---

## 1. 正本言語

大規模言語モデル最小成立規定の正本言語は日本語とする。

> **定義・対象・関係・境界・同一性・判定・禁止・保留・再開放条件は、日本語本文だけで再構成可能でなければならない。**

英語その他の言語版は、日本語正本からの二次射影とする。

---

## 2. 英語名称の位置

LLM / Layer-0 / model / runtime等の外部語は利用できる。

ただし、それらは、

- 外部互換名称
- 引用
- 実装固有名称
- 検索キー
- 機械識別子

としてのみ使う。

日本語正本に存在しない意味差を、英語名称から逆輸入してはならない。

---

## 3. 日本語先行規則

新しい概念を規定へ追加するときは、次の順序を守る。

1. 何を対象として切り出すかを日本語で書く。
2. 何と何の関係かを日本語で書く。
3. 何を含み何を除くかを日本語で書く。
4. 何をもって成立・不成立・保留とするかを日本語で書く。
5. 必要なら外部互換の英語名称・略号を後から付ける。

英語名を先に置き、その訳語を後から作る順序を正本規定では採用しない。

---

## 4. 機械識別子の従属

コード・JSON・CI等の都合で英語識別子を使う場合、識別子は日本語定義への参照札とする。

```text
機械識別子
→ 日本語正本の定義ID
→ 日本語の意味
```

の順序を固定する。

機械識別子の名称から正本語義を導いてはならない。

### 例

外部識別子が `CONTEXT_STATE` であっても、日本語正本が「文脈に応じた形成関係の条件面」と規定しているなら、`state`という英単語を根拠に独立componentへ再物象化してはならない。

---

## 5. 状態語

正本判定の一次状態語は日本語とする。

- 成立
- 不成立
- 保留
- 対象外
- 未観測
- 未確定
- 矛盾
- 留保
- 再開放

PASS / FAIL / SUSPEND / OPEN 等は外部互換表示として併記可能だが、日本語状態を上書きしない。

---

## 6. 規範語

正本の拘束語は日本語で書く。

- 必須
- 禁止
- 許容
- 推奨
- 保留
- 対象外

MUST / SHALL / SHOULD / MAY 等を一次拘束語にしない。

外部仕様へ翻訳する場合のみ対応表を作る。

---

## 7. 引用原文の扱い

英語等の一次資料を証拠として使うことは当然に許容する。

ただし正本へ取り込むときは、

1. 原文を証拠として保持する。
2. 日本語で観測内容を分別する。
3. 原文語と日本語規定語を同一視しない。
4. 翻訳で失われる残差を残す。

を要求する。

原文が`model`と呼んでいるから、本規定でも同じ境界の「モデル本体」と扱う、という自動昇格を禁止する。

---

## 8. 訳語固定の禁止

日本語正本は単語対単語の固定辞書ではない。

例えば、

- model
- state
- generation
- context
- layer
- core

は、文脈によって日本語上の切り出しが変わり得る。

一対一訳を正本原理へ昇格しない。

必要な場合は、その文書・版・対象での意味を日本語で再定義する。

---

## 9. 日本語正本の自己監査

正本候補を公開・確定する前に、次を監査する。

### J1

英語語を全て削除しても、日本語本文だけで意味が再構成できるか。

### J2

英語略号を別の略号へ置換しても、日本語の対象・関係・境界が変わらないか。

### J3

外部資料の英語カテゴリを、そのまま日本語カテゴリへ写していないか。

### J4

日本語本文にしか存在しない関係差が、英訳時に欠損する可能性を記録しているか。

### J5

日本語規定語の定義が、英語一般語義を暗黙参照しなくても閉じるか。

一つでも閉じない場合、正本確定を保留する。

---

## 10. 正本と翻訳版

日本語正本と他言語版が食い違う場合、日本語正本を優先する。

ただし、日本語正本自体が絶対真理という意味ではない。

新観測により日本語正本が改訂される場合、

- 旧版
- 変更理由
- 語義差
- 影響範囲
- 他言語版への反映状態

を保持する。

---

## 11. 現在の正式名称候補

日本語一次名称候補:

> **大規模言語モデル 最小成立規定（仮）**

外部互換名称:

> LLM Layer-0 / Layer-0 Functional Specification

外部互換名称から日本語正本の構造を逆定義しない。

---

## 12. 現在の禁止事項

- 英語名を先に作って日本語訳を正本と称すること。
- English identifierの粒度を日本語責任数へそのまま写すこと。
- 英語一般語義を日本語正本の暗黙辞書にすること。
- 翻訳しやすさを理由に日本語の関係差を削ること。
- 機械実装都合を理由に日本語規定を英語スキーマへ従属させること。

日本語は表示言語ではなく、定義・分別・規定の基底言語として扱う。
