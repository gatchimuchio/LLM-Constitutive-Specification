# 対象言語関係の独立固定と非循環監査

状態: 正本補助候補 / 未確定 / 再開放可

日付: 2026-08-25

---

## 0. 問題

基底成立規定では、

> 対象言語関係に対応する模型形成関係

を言語模型成立の中心候補としている。

しかし、対象言語関係を候補模型自身の出力から作ると、

```text
模型が出した
→ それを対象関係と定義する
→ 模型は対象関係に対応した
```

という循環が成立する。

これを禁止する。

---

# 1. 対象側を先に固定する

対象言語関係は、候補模型の採否評価より前に、候補模型から独立して固定する。

固定するのは絶対真理ではない。

現行対象範囲・版・観測条件における**対象言語関係候補**である。

---

# 2. 対象言語関係候補の作り方

少なくとも次を利用できる。

- 人間が実際に用いる自然言語例
- 文脈対照
- 語順・照応・否定・条件等の対照
- 正負例
- 意味を保つ言い換え
- 意味を変える最小変更
- 翻訳対応
- 欠損復元対照
- 独立した言語資料・辞書・コーパス・仕様

特定benchmarkを普遍基準へ固定しない。

---

# 3. 対照単位

対象言語関係候補は、単独の正解文だけでなく、**差**として記録する方を優先する。

例:

```text
文脈A → 候補Xが成立しやすい
文脈B → 候補Yが成立しやすい
```

または、

```text
表現Aと表現Bは対象範囲で同じ関係を保つ
表現Aと表現Cは対象範囲で関係が変わる
```

この差を候補模型の形成差と照合する。

---

# 4. 候補模型から独立させる

禁止:

- 候補模型の生成文をそのまま教師へする。
- 候補模型のscore順を対象言語側の正解順として採用する。
- 候補模型の内部座標を、自然言語側の本来構造として逆投影する。
- 候補模型が理解できない関係を、対象言語側から削除して適合させる。

---

# 5. 模型側の観測

対象側を固定した後、候補模型について、

- 入力言語状態
- 文脈差
- 模型作用
- 言語形成差
- 表出結果

を観測する。

内部非公開の場合は、外部から確認できる形成機能だけを扱い、内部作用を推測しない。

---

# 6. 対応の読み方

対応は完全同型を要求しない。

現行対象範囲・観測条件で、

> **対象側で区別した言語差が、候補模型側の形成差へ再現可能に反映されるか**

を見る。

### 局所適合

対象差が期待される方向へ形成差として安定して現れる。

### 不適合

対象差と無関係、逆方向、または再現不能な差しか生じない。

### 未確定

証拠不足、条件依存、矛盾、外周機構との分離不能等。

---

# 7. random mappingへの適用

random mappingは、

```text
入力
→ 何らかの差
```

を生じさせられる。

しかし、候補模型から独立して固定した対象言語差に対して、再現可能な対応を持たなければ局所適合しない。

これにより、入出力型だけが同じrandom系を排除できる。

---

# 8. 形成関係と形成差の位置

`模型形成関係`と`言語形成差`を二つの独立構成要素にしない。

一つの関係を、

```text
入力側: 文脈付き内部言語状態
作用側: 模型形成関係
結果側: 言語形成差
```

として三方向から観測しているだけである。

正本の最小中核は、より短く、

> **文脈付き言語状態に応じて、未提示・未確定の言語状態の成り立ちへ差を生じさせる形成関係**

と表せる候補を置く。

---

# 9. 対応確認は観測側

対象言語関係候補と模型形成関係の対応は、現行Projection上の成立候補として置く。

その対応をこちらが確認したかどうかは観測状態である。

```text
対応候補
≠
対応確認済み
```

を維持する。

---

# 10. 正本への帰結

基底成立規定の中核を、次へ再圧縮する候補を強く支持する。

> **言語模型とは、候補模型から独立して固定した対象言語関係候補に対し、文脈付き言語状態に応じて未提示・未確定の言語状態へ形成差を生じさせる関係が、現在の対象範囲・版・観測条件で局所的に対応している模型である。**

ただし、この一文自体も次巡でさらに削る。

---

# 11. 次の監査

1. 対象言語関係候補を「差」だけで十分に記述できるか。
2. 意味保持・意味変更等の対照を自然言語全域へ一般化しすぎていないか。
3. 生成以外の言語模型で同じ非循環監査を使えるか。
4. black-box閉鎖模型でも同じ適合評価を再現可能にできるか。
