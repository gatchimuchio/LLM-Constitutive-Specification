旧称`Layer-0`の構成要素・責任名を使わず、既存HDS構文化と公開実装から、実在する大規模言語模型に共通する成立関係を日本語で再抽出する。

## 1. 既存HDS横断観測から維持する境界

既存の横断構文化では、少なくとも次の分離が既に必要と観測されている。

1. 模型本体と推論実行系を分ける。
2. 模型本体とエージェント・道具・安全分類器等を分ける。
3. 系列方向の情報流、深さ方向の情報流、幅方向の情報流を同一視しない。
4. 入力媒体前段と中央言語処理を同一視しない。
5. 形成過程と展開後制御を同一視しない。
6. 同名系列でも版・時点を跨いで情報を逆流させない。
7. 閉鎖模型では可観測機能から内部構造を推測しない。

これらは新規定でも維持する。

ただし、これらをそのまま「最小構成要素一覧」へ昇格しない。

---

## 2. Llama 3

元HDS構文化では、少なくとも次の経路が分別されている。

```text
文字列
→ 言語住所化
→ 内部言語状態
→ 文脈を用いた反復変換
→ 語彙上の内部結果差
→ 表出選択
→ 次の言語状態
```

重要な観測:

- 既出文脈の差が次の内部結果差へ作用する。
- 模型内部の語彙上の結果差と、単発の表出結果は別である。
- 同じ模型と文脈でも表出条件の変更で単発結果が変わり得る。
- 学習・後学習・評価・安全系・物理運用は別成立物として分別できる。

新規定への抽出:

> **文脈付き言語状態から、未提示言語状態についての言語形成状態を生じさせる関係**

が中央に残る。

---

## 3. OLMo 3 と Qwen3.6

横断HDSでは、両者は粗視化すると局所系と全体系の周期配置を持つが、局所作用の種類が異なることが観測されている。

- OLMo 3: 局所窓による明示参照を中心とする。
- Qwen3.6: linear / recurrent型の状態更新と全体参照を周期配置する。

したがって、

> **文脈が効くこと**

と、

> **文脈をどう保持・参照・更新するか**

は別である。

前者は成立関係候補、後者は個別実現である。

---

## 4. DeepSeek V4 と Kimi K3

横断HDSでは、系列方向の参照・圧縮・選択と、深さ方向の輸送、幅方向の専門経路が別軸として観測されている。

例:

- DeepSeek V4: 局所・圧縮・長距離参照、mHC、MoE等。
- Kimi K3: KDA / MLA、AttnRes、LatentMoE等。

重要なのは、これらの固有機構名を削っても、

```text
文脈付き言語状態
→ 模型内部の形成作用
→ 未提示言語状態に関する内部結果差
```

が残ること。

したがって、

- Attention
- MoE
- Dense
- 圧縮
- routing
- residual形式

を普遍必須へ昇格しない。

---

## 5. Apertus 1.5

中央の言語処理構造を維持しながら、入力媒体や後学習能力を拡張できる自然実験として扱える。

ここから、

> 能力追加・媒体追加 = 中央言語形成関係の全面刷新

とは限らないことが分かる。

入力媒体前段・言語住所対応・中央形成関係・利用機能を分けて観測する。

---

## 6. K2-V2

長文脈形成・物理分割・実行効率を分離して観測する。

文脈長や計算配置が変わっても、上位では、

> 文脈差が言語形成状態へ作用する

という関係へ写る。

長文脈そのものを言語模型成立の唯一形式へしない。

---

## 7. LLaDA-8B

非自己回帰の追加証人。

公式生成実装では、概ね次の関係を持つ。

```text
prompt + 未確定位置
→ 模型による各位置の内部結果差
→ 一部位置の確定・更新
→ 残り未確定位置へ再適用
→ 結果言語状態
```

自己回帰型の、

```text
既出列
→ 次位置形成
→ 一位置確定
→ 反復
```

とは異なる。

それでも上位では、

> **文脈付き言語状態から、未提示・未確定の言語状態について言語形成状態を生じさせる**

という関係が残る。

このため、次を普遍必須から外す。

- 左から右
- 一位置ずつ
- 自己回帰
- 次tokenだけを対象にすること
- KV cache

## 8. 確率分布の位置

Qwen系、DeepSeek V4、Kimi K3等では模型本体がまずsoftmax前の値列を形成し、その後の生成処理が選択・正規化等を行う経路を確認できる。

LLaDAでも模型出力の後に、温度、softmax、argmax、confidence、remasking等が接続される。

したがって、普遍に残すべきなのは、

> **未提示言語状態について形成差を持つ内部結果を生じさせること**

であり、確率分布そのものではない。

確率的実装は許容するが必須にしない。

---

## 9. 大規模性と汎用性

一般目的模型だけを観測すると、「大規模」と「汎用」を混同しやすい。

金融、生医療、コード等へ特化した大規模言語模型が存在するため、次を分ける。

- **大規模性**: 対象領域内での状態域・関係域・共有適用域の規模。
- **汎用性**: 異なる用途・領域へ同じ模型を再利用できる広さ。

領域特化を理由に大規模言語模型から排除しない。

## 10. 横断して残る成立候補

現時点で最も強く残るのは次である。

### A. 対象側

自然言語に、文脈と未提示・未確定状態の成り立ちに関する関係を切り出せる。

### B. 模型側

模型が、文脈付き内部言語状態から、未提示・未確定の言語状態について差を持つ内部結果を生じさせる関係を持つ。

### C. 対応側

現行対象範囲・版・観測条件において、対象側の関係差と模型側の形成差が対応する候補関係を置ける。

### D. 規模側

その形成関係が、対象領域内の大きな状態域・関係域・共有適用域へ成立する。

## 11. 横断して残らないもの

次は現時点で実装固有または別階層へ落ちる。

- Transformer
- Attention
- Dense / MoE
- 自己回帰
- 左から右
- 次語予測
- 確率分布
- softmax
- sampling
- 特定tokenizer
- KV cache
- 特定残差構造
- 学習目的
- safety classifier
- tool use
- agent loop

## 12. 現在の判断

現時点の観測から、旧`Layer-0`を「六つ前後の同格な最小構成要素」として維持する根拠は弱い。

一方、旧規定が観測した、

- 言語住所化
- 文脈利用
- 内部形成作用
- 条件付き内部結果
- 学習
- 表出

という事象自体は、多くが残る。

主要修正は、**観測事象の削除ではなく、帰属階層と関係の再配置**である。

## 13. 次の反例監査

次を優先する。

1. 文脈依存を欠く射程内の実在大規模言語模型が存在するか。
2. 言語形成状態という語が、決定論的・非確率・非ニューラル実装へ過不足なく適用できるか。
3. 言語住所対応を模型同一性へ必ず含める必要があるか。
4. 大規模性の三観測面をさらに統合できるか。
5. 生成型ではない大規模言語模型を同一規定へ含めるか。
6. 閉鎖模型で、内部形成関係をどこまで主張してよいか。

この反例監査が閉じるまで正式名称を確定しない。
