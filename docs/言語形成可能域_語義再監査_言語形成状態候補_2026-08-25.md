# 「言語形成可能域」語義再監査 — 「言語形成状態」候補

状態: 作業中 / 非正本 / 再開放可

日付: 2026-08-25

---

## 0. 問題

これまで、モデル中核の結果側を、

> 言語形成可能域

と呼んできた。

この語は、

- 複数候補の集合
- probability distribution
- score vector

のような構造を暗黙に連想させる。

しかし、正本ではこれらを普遍形式へ固定したくない。

決定論的singleton、直接状態遷移、diffusion途中状態等も損失なく扱う必要がある。

---

## 1. 必要な意味だけを残す

モデル中核の結果側に必要なのは、

> **現在まだ完成形として入力されていない言語状態について、その成り立ちを区別・制約・確定するための差を含む内部結果状態**

である。

候補集合である必要はない。

確率である必要もない。

---

## 2. 新語候補 — 言語形成状態

### 定義候補

> **言語形成状態とは、現在の文脈付き言語状態に対するモデルrelationの結果として生じ、未提示・未確定の言語状態について、その成り立ちを区別・制約・確定できる内部結果状態である。**

---

## 3. 実装別写像

### Causal LM

```text
context
→ logits / score
```

logits等が言語形成状態の実装になる。

### Deterministic transition

```text
context
→ one next state
```

一意の次状態そのものが言語形成状態になり得る。

### Hard candidate model

```text
context
→ allowed candidates
```

候補集合が言語形成状態。

### Diffusion LM

```text
masked / partially formed state
→ token-wise formation scores / proposals
```

各反復の出力が言語形成状態。

---

## 4. 言語形成状態と外部言語結果

言語形成状態は外部言語結果と同一ではない。

### 複数候補の場合

表出作用が候補を選択・更新する。

### singletonの場合

表出作用が実質的に恒等・接続だけになる場合がある。

### diffusionの場合

形成状態と表出更新を複数回反復する。

従って、

> 表出作用が常に高度な独立機構である

とはしない。

ただし、

> モデルrelationの結果状態

と、

> 外部で観測される完成言語結果

の概念差は保持する。

---

## 5. 「可能域」を残すか

### 利点

- score/distribution/candidate setを直感的に書ける。

### 欠点

- 集合・多候補を暗黙化する。
- singleton / deterministic transitionで不自然。
- diffusion途中stateを無理にcandidate domainへ読ませる。

### 現在判定

正本の上位語としては、

> **言語形成状態**

の方が小さい。

`形成可能域`は、複数候補・score空間を持つ実装の下位語として残す候補。

---

## 6. 中核関係・修正版

旧:

```text
文脈付き内部言語状態
→ model relation
→ 言語形成可能域
```

修正候補:

```text
文脈付き内部言語状態
→ 模型形成関係
→ 言語形成状態
```

### 定義文候補

> **模型形成関係とは、文脈付き内部言語状態に応じて、未提示・未確定の言語状態について差を持つ言語形成状態を生じさせる関係である。**

---

## 7. 対象言語側との対応

モデル内部の言語形成状態がrandomな差を持つだけでは足りない。

対象自然言語側で宣言した、

- 継続
- 復元
- 変換
- 適合

等の対象言語relationと対応する必要がある。

対応確認を別監査面として維持する。

---

## 8. 旧Layer-0への影響

旧 `CONDITIONAL_LINGUISTIC_OUTPUT_SURFACE` の新しい上位再配置候補は、

> **言語形成状態**

となる。

`output surface`という語から外部text surfaceを導入しない。

---

## 9. 現時点の判定

- 「言語形成可能域」を普遍正本語にする: 再開放
- 「言語形成状態」を上位正本語候補にする: 強く支持
- probability / score / set / singletonのいずれかへ固定: 禁止候補

---

## 10. 次の監査

1. 「状態」という語が静的実体化を招かないか。
2. model relationの結果を「差」だけで規定する案との比較。
3. 形成状態が文脈自身を更新するrecurrent modelで入出力を分けられるか。
4. 形成状態と内部memory updateが同時に返るモデルの扱い。
