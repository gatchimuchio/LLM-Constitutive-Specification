# 2. Llama 3 — D3

## T

**強く観測。**

元HDS構文化で、

- 文字列→tokenizer/BPE→token ID列→embedding
- 既出token列から次token候補形成
- pretrainingのnext-token prediction

が明示される。

従って2024-04 Llama3の主要language target relationとして、少なくとも**既出言語系列に条件づけられた次token関係**を置ける。

ただし`next-token`を他modelへ普遍化しない。

## M

**強く観測。**

trained parameters + Transformer relation。

global causal attention、GQA、FFN、residual等はMの実装topology。

## C

**支持あり。**

公開生成・評価・pretrained/Instruct形成の観測が存在する。

ただしbenchmark score単体をCへ固定せず、prompt/decoding/scoring条件込みのrelation evidenceとして扱う。

## X

**強く観測。**

```text
token state
-> embedding
-> repeated Transformer blocks
-> logits
-> decoding
-> next token state
```

# 8. 第一巡の重要な結果

## 8.1 新定義はarchitecture差へ過適合していない

M/Xでは、

- global dense
- sliding/full hybrid
- linear/recurrent hybrid
- compressed/sparse attention
- KDA/MLA
- Dense/MoE

の差を越えてT/M/C/Xへ射影可能である。

## 8.2 しかしT/C証拠は既存HDS資産で不均一

過去構文化は主にarchitecture/formation/relative structureを目的としており、v5のTarget Projection / Language Conformance用に作られていない。

従って、

```text
M/Xが見える
=>
T/Cも確定
```

とはしない。

## 8.3 K3のD4を過大評価しない

weight全数監査はMの証拠密度を最大化する。

T/Cを同じD4へ自動昇格しない。

## 8.4 MINIDORAを基準器にしない

新Layer-0はMINIDORAがPASSするように定義しない。

現時点ではMINIDORAのT/M/CはOPENのまま保持する。
