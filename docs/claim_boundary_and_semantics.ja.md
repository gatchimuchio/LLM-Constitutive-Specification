# 主張境界と意味 — v4

現行評価器の直接主張は **candidate-local functional conformance** である。

一方、2026-08-21の横断証拠により、観測済み5モデル系統については **L0-C: 異種architecture family間の機能責任再現** が支持された。

| 層 | 状態 |
|---|---|
| L0-A candidate-local conformance | executable / current |
| L0-B architecture-family recurrence | supported in observed families |
| L0-C cross-family responsibility recurrence | **supported in observed five-model set** |
| L0-D scoped provisional principle | `PRINCIPLE_CANDIDATE / REOPEN_REQUIRED` |
| L0-E transfer candidate | open |

## 境界

L0-Cの支持から次を自動導出しない。

- 5責任が普遍的一意最小である。
- 世界中の全LLMを観測した。
- standard attention一般が不要である。
- neural network一般が不要である。
- candidate-local PASSだけで通常語義のLLMと同値になる。

今回の証拠が直接支持するのは、**観測した異種family間で、実装機構の差を越えて同じ5責任語彙が維持できた**という範囲である。

`UNIVERSAL_PRINCIPLE` / `FINAL_MINIMUM` は現行statusとして使用しない。
