# 規模記述 三観測面 — 独立性監査

状態: 正本補助候補 / 未確定

日付: 2026-08-25

---

## 0. 問い

規模記述として置いた、

1. 状態域規模
2. 関係域規模
3. 共有適用規模

を一つへ統合できるか。

---

# 1. 状態域規模

**状態域規模**は、対象領域で区別・受理・形成できる言語状態の範囲を記述する。

例:

- 語彙・表現形式が広い。
- 長い状態列を扱える。
- 多様な表記・粒度を扱える。

---

# 2. 関係域規模

**関係域規模**は、対象領域で形成関係が扱える言語関係の種類・距離・階層を記述する。

例:

- 局所語順だけでなく長距離照応を扱う。
- 条件・否定・依存・入れ子等を扱う。
- 複数段の文脈関係を保持する。

---

# 3. 共有適用規模

**共有適用規模**は、同一の言語関係同一性を、どれだけ多数の異なる状態・文脈・組合せへ共有して適用できるかを記述する。

個別ケースごとに別模型へ交換する場合とは分ける。

---

# 4. 状態域と関係域は統合できない

### 反例候補A

非常に大きな語彙・状態表を持つが、局所的な浅い関係しか扱わない系。

```text
状態域規模 = 大
関係域規模 = 小
```

が成立し得る。

### 反例候補B

扱う記号集合は小さいが、長距離・階層的な関係を扱う系。

```text
状態域規模 = 小〜中
関係域規模 = 大
```

が成立し得る。

従って二つを一軸へ潰すと差を失う。

---

# 5. 共有適用規模も独立する

### 反例候補C

大きな状態集合と複雑な関係を扱うが、用途・区間ごとに多数の別模型を切り替える系。

個々の局所模型の共有適用規模は小さくても、システム全体の状態域・関係域は大きく見える。

### 反例候補D

一つの模型関係が、状態表現自体は比較的小さくても、多数の文脈・組合せへ反復適用される系。

共有適用規模だけが大きい場合がある。

従って共有適用規模も別に保持する必要がある。

---

# 6. 上位語

三観測面を上位概念として、

> **適用規模**

と呼ぶことはできる。

ただし正本監査では三観測面を失わない。

```text
適用規模
├─ 状態域規模
├─ 関係域規模
└─ 共有適用規模
```

---

# 7. 汎用性は別

異なる業務・分野・媒体へ使えることは、三観測面と関連するが同一ではない。

金融特化、生医療特化、コード特化等の大規模言語模型が成立し得るため、汎用性・領域横断性を規模の必須条件にしない。

---

# 8. 物理規模は別

- パラメータ数
- 重み容量
- 規則数
- 表の行数
- 記憶容量
- 計算量

等は実装物理規模である。

規模記述の重要証拠にはなるが、状態域・関係域・共有適用域と同一ではない。

---

# 9. 現在判定

三観測面は、少なくとも概念上独立する反例を構成できる。

したがって、現時点では統合しない。

ただし、これらは**言語模型成立中核の構成要素ではなく、規模を記述する監査軸**として保持する。

`大規模`という通常語の適用は、時点・比較集合・用途に依存し得るため、一点普遍閾値を置かない。
