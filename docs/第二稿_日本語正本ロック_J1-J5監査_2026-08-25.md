# 第二稿 — 日本語正本ロック J1-J5監査

状態: 監査中 / 非正本

日付: 2026-08-25

対象: `大規模言語モデル_最小成立規定_日本語正本候補_第二稿_2026-08-25.md`

---

# 0. 結論

第二稿は第一稿より日本語基底へ近づいたが、**日本語正本としては未合格**。

主な理由:

1. 外来語由来の概念骨格が一部残る。
2. 規定語の自己完結定義が不足する。
3. 実装例と正本語が同じ行で混在し、語義の上下関係が曖昧。
4. `モデル`という外来慣用語を内部正本語として多用している。
5. 自然言語・文脈・形成・対応・模型等の基底語が第二稿単体では完全に閉じない。

---

# 1. J1 — 英語を全削除して意味が再構成できるか

## 判定: **概ね可 / 一部不合格**

定義の中心は日本語で読める。

しかし、次が残る。

- model
- relation
- artifact
- runtime
- profile
- component
- token
- logits
- probability
- sampling

実装例として使う分にはよいが、`
モデルrelation`
等の混成語が正本本文に残る箇所は不合格。

### 修正

正本一次語を次へ寄せる。

```text
model        → 模型
relation     → 関係
artifact     → 模型物 / 成立物
runtime      → 実行系
profile      → 観測面 / 特性
component    → 構成要素
version      → 版
scope        → 対象範囲
```

固有実装名は括弧・実装例・外部資料欄へ分離する。

---

# 2. J2 — 英語略号を置換しても意味が変わらないか

## 判定: **合格寄り**

第二稿の中核は、旧T/M/C等の英語略号へ依存していない。

ただし、外部互換名称 `Layer-0` が文書名・作業会話で強く使われるため、正本内部の正式名称を別に固定する必要がある。

### 正本内部名称候補

> **大規模言語模型 最小成立規定**

### 外部慣用名称

- 大規模言語モデル
- Large Language Model
- LLM
- Layer-0

外部名称を正本語義へ逆流させない。

---

# 3. J3 — 外部カテゴリを日本語カテゴリへ直写ししていないか

## 判定: **一部不合格**

残存箇所:

- `model core`
- `operational closure`
- `profile`
- `artifact`

を日本語化しただけの章構成が一部残る。

### 修正方針

外部カテゴリ名から章を作らず、HDSの対象・関係・作用・境界から章を再編する。

候補:

```text
対象範囲
対象言語関係
模型形成関係
言語住所対応
言語形成状態
表出作用
模型同一性
規模資格
観測・採否
形成履歴
利用外周
```

---

# 4. J4 — 日本語側の関係差が翻訳で欠損することを記録しているか

## 判定: **未閉包**

第二稿は日本語優先を述べるが、具体的な翻訳残差規則が弱い。

### 追加候補

外部翻訳版には最低限、

- 日本語正本語
- 翻訳語
- 一対一対応不可の注記
- 欠損し得る意味差
- 日本語正本参照位置

を持たせる。

特に、

- 形成
- 成立
- 状態
- 関係
- 対応
- 境界
- 留保
- 再開放

を単純一語翻訳で固定しない。

---

# 5. J5 — 日本語規定語だけで閉じるか

## 判定: **不合格**

第二稿単体で明示定義が不足する語:

- 自然言語
- 文脈
- 模型
- 形成
- 関係
- 対応
- 同一性
- 大規模資格

一部は前段文書に定義があるが、正本候補は外部草案を読まなくても自己完結する必要がある。

---

# 6. 規定語の再構成候補

## 6.1 模型

> **対象として切り出した関係の一部を、複数の対象状態へ再利用可能な内部関係として保持・適用する成立物。**

対象そのものではない。

## 6.2 関係

> **二つ以上の状態・差異・範囲の間で、一方の違いが他方の区別・成立・変化の読み方へ作用する結びつき。**

この定義も暫定。

## 6.3 文脈

> **現在の言語状態について、別の状態・配置・履歴・条件との結びつきにより、形成結果の差へ作用する周辺関係。**

## 6.4 形成

> **現在与えられた状態だけでは完成していない対象について、次にどの状態が成立し得るかの差を生じさせること。**

外部文章出力だけを意味しない。

## 6.5 対応

> **異なる二つの表現域・状態域で、片方の差が他方の差と一定の規則で結びつくこと。**

同一性を意味しない。

## 6.6 同一性

> **版内で、差が存在しても同じ成立物・同じ関係として扱う境界規則。**

絶対的な本質同一を意味しない。

---

# 7. `モデル` と `模型`

日本語正本内部では、`模型`を一次語にする案を強く支持する。

理由:

- `model`の英語一般語義へ依存しにくい。
- 対象そのものではなく有限な写しである、という神域/HDS境界を語自体で保持しやすい。
- `モデル`を外部慣用名称として別扱いできる。

### 候補

```text
正本内部: 大規模言語模型
外部慣用: 大規模言語モデル / LLM
```

ただし一般公開時の可読性との関係は別監査する。

---

# 8. 判定

```text
J1 = 一部不合格
J2 = 合格寄り
J3 = 一部不合格
J4 = 未閉包
J5 = 不合格
```

従って第二稿は正本化しない。

第三稿では、

1. 規定語辞書を本文内に統合する。
2. `模型`を正本一次語にする。
3. 英語混成語を実装例欄へ隔離する。
4. 章立てを日本語の対象・関係・作用・境界から再構成する。
5. 翻訳残差規則を追加する。

ことを要求する。
