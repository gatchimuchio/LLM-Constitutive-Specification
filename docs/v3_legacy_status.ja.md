# v3 Legacy Status

v3.0の6役割モデル、Layer A 64部分集合列挙、生成artifact、tag/releaseは再現性と研究履歴のため保持する。

現行mainでは次のように再分類する。

- 6役割語彙: `LEGACY_LOCAL_MECHANISM / AUDIT_VOCABULARY`
- Layer A: `DECLARED_GRAPH_INTERNAL_CERTIFICATE`
- 既知family mapping: `PUBLIC_WITNESS_MAPPING`
- 「現代LLM一般への普遍的一意最小性」: `WITHDRAWN_FROM_CURRENT_CLAIMS`

理由は、v3の定義域が学習済みparameterized transform・sequence fitting・emission等を先に含み、その定義域に対して同じ役割の必要性を再導出していたためである。これは定義域内の含意としては成立するが、実在LLM一般への独立した普遍必要性証明ではない。

v3 releaseそのものは改変しない。v4は別claim boundaryとしてmain上に積み上げる。
