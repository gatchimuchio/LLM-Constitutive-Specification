# 名称再開放・日本語基底・外部言語例外規定

状態: 正本候補 / 未確定 / 再開放可

日付: 2026-08-25

---

## 0. 修正理由

これまでの再定義作業は、旧称 `Layer-0` を実質的な正本名称として残したまま、内部定義だけを作り直していた。

しかし `Layer-0` は、当時「最初に置く基底層」程度の作業上のニュアンスで暫定的に付けた名称に過ぎない。

従って、名称そのものを再開放する。

`Layer-0` という語から、

- layer構造
- 0番目という順序
- component hierarchy
- lower/higher layer

等を現在規定へ逆輸入しない。

---

## 1. 名称の地位

### 1.1 旧称

`Layer-0` / `LLM Layer-0` は**歴史的・外部互換上の旧称**へ降格する。

### 1.2 正本名称

正本名称は、規定内容が閉じた後に日本語で決める。

名称を先に固定し、その名称へ構造を合わせない。

### 1.3 暫定呼称

作業中は必要に応じて、

- 大規模言語模型 最小成立規定
- 言語模型 最小成立規定
- 基底規定

等の日本語暫定名を使用できる。

ただし、いずれも正本確定前は仮称とする。

---

## 2. 日本語基底の原則

本規定における日本語基底とは、表示言語が日本語であることではない。

> **対象の切り出し、関係の分別、境界の設定、状態の命名、成立・不成立・保留の判定、再開放条件の記述を、最初から日本語で行い、日本語だけで意味が閉じること。**

これを正本原則とする。

---

## 3. 他言語の地位

他言語は、実務上やむを得ない場合にのみ許容する。

### 許容例

- 外部API / SDK / protocolの固定名称
- 既存標準の正式識別子
- 外部repository / package / class / function名
- 公式論文・仕様・model cardの原文引用
- 機械実装が英数字識別子を要求する場合
- 国際公開用の翻訳版
- 外部サービスとの相互運用

### 不許容

- 日本語で十分に規定できる概念を、英語名のまま正本骨格へ置く
- 英語の一般語義を正本語義として無言流用する
- 英語のカテゴリ分けを日本語規定の章立てへそのまま写す
- 実装上の英語識別子を、正本の概念単位へ逆昇格する

---

## 4. 他言語使用時の規則

他言語を使用するときは、原則として次の順序を守る。

1. 日本語で対象・関係・境界を規定する。
2. 必要なら外部対応名を付記する。
3. 外部対応名に固有の意味差がある場合は残差を記録する。
4. 他言語側の表現から日本語正本を逆解釈しない。

---

## 5. 機械識別子

コード・JSON・CI・外部仕様の都合で英数字識別子を用いる場合、識別子は正本語義を持たない。

```text
機械識別子
→ 日本語正本語・定義位置
→ 日本語の意味
```

の従属関係を固定する。

必要なら日本語識別子をそのまま使用してよい。

Python等で日本語識別子が技術的に利用可能であり、外部互換上の支障がない場合は、日本語を優先してよい。

---

## 6. 規定言語の優先順位

同一版について、

1. 日本語正本
2. 日本語正本に対応づけた機械仕様
3. 他言語翻訳版
4. 外部向け説明文

の順に優先する。

食い違いがある場合、下位文書を正本へ合わせる。

ただし、日本語正本自体も新観測によって再開放できる。

---

## 7. 「Layer-0」由来の構造を禁止する

旧称が `Layer-0` であることだけを理由に、次を要求しない。

- 単一の最下層が存在すること
- 上位Layer / 下位Layerがあること
- 0,1,2...の階層番号を持つこと
- 一方向の積層構造であること
- 物理componentの順序と概念上の基底が一致すること

新規定は、観測から必要になった関係・境界だけを持つ。

---

## 8. 「最初の層」という旧ニュアンスの保持

旧称が表していた有効な意図は、

> **上位の製品機能・エージェント機能・評価・応用へ進む前に、LLMそのものの成立条件を最初に確認する基底規定**

という程度である。

この意図は保持できる。

ただし、それを物理的なLayer構造へ物象化しない。

---

## 9. 正本再構築への影響

名称再開放により、正本候補の作り方を次へ変更する。

旧:

```text
Layer-0とは何か
→ Layer-0のcomponentを定義
```

新:

```text
大規模言語模型とは何が成立している対象か
→ 対象・関係・境界を日本語で観測
→ 最小成立規定を閉じる
→ 最後に名称を決める
```

---

## 10. 現在の作業名称

当面、内部作業上は

> **大規模言語模型 最小成立規定（仮）**

を使用する。

`Layer-0` は旧資料・外部互換・検索性維持のために括弧書きで参照できる。

例:

> 大規模言語模型 最小成立規定（旧称: Layer-0）

ただし、正本確定後により適切な日本語名称が得られた場合は変更する。

---

## 11. 次の作業

1. 第二稿から `Layer-0` 前提の章構造・語彙を除去する。
2. `モデル` / `relation` / `runtime` 等の混成語を日本語正本語へ置換する。
3. 日本語正本だけで対象・成立関係・大規模資格・運用境界が閉じる第三稿を作る。
4. 英語識別子は別冊の外部互換表へ分離する。
5. 第三稿を実在模型群へ逆適用する。
6. その後にのみ、旧称 `Layer-0` を残すか完全廃止するか決める。
