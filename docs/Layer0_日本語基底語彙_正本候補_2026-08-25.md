# 言語模型最小成立規定 — 日本語基底語彙（正本候補・仮）

状態: 草案 / 非正本 / 再開放可

## 0. 目的

本書は、旧Layer-0が暗黙に借用していた英語圏の `language / model / large / core / conformance` 等の概念境界を前提にせず、日本語正本で使用する基底語を先に規定する。

単なる訳語表ではない。各語が何を切り出し、何を含まず、何と関係するかを日本語で閉じる。

## 1. 言語

本規定における「言語」とは、単独の文字・token・音・単語の集合そのものではない。

> **言語とは、表現単位の差異が、配置・順序・文脈・対応・慣用・規則等の関係によって、他の状態との差を再現可能に生じさせる体系である。**

重要:

- 記号単体を言語としない。
- 語彙数だけを言語の広さとしない。
- 自然言語だけに限定しない。コード・形式言語等を対象に含める場合は、その時点の対象範囲を明示する。
- 「意味」を模型内部の実体として先取りしない。何を意味関係として扱うかは対象ごとに観測する。
- 口語・文語・文字・音声・画像等の媒体を、言語そのものと同一視しない。媒体は言語関係の表出・接続形態である。

### 言語状態

> **言語状態とは、ある時点・文脈・範囲で、言語の差異と関係を区別可能にした局所状態である。**

文字列、token列、embedding、hidden state、HDS座標等は言語状態の実装・射影候補であり、言語状態そのものの普遍形式ではない。

### 言語関係

> **言語関係とは、複数の言語状態または状態内成分の間に、差異・順序・対応・依存・復元・継続・文脈化等として観測される関係である。**

何を言語関係とみなすかは対象・版・範囲ごとに明示し、一覧を最終集合として固定しない。

## 2. 模型

本規定における「模型」は、対象そのものではない。

> **模型とは、対象について切り出した関係の一部を、特定の目的・条件・観測範囲で再利用可能に区別・対応・予測・復元・変換できるよう、有限な成立物へ写した関係構造である。**

したがって、

```text
対象 ≠ 模型
対象関係 ≠ 模型内部関係
```

を版内規定として固定する。

### 模型物

重み、規則、表、グラフ、状態遷移、プログラム、複合データ構造等として、版・設定・内容を局所的に同定できる成立物。

### 模型関係

模型物が、対象状態に対応づけられた内部状態間で再利用する関係。

模型物と模型関係は同一ではない。同じ模型物が複数の模型関係を担ってよい。

### 再利用

本規定でいう再利用とは、対象入力ごとに別模型へ交換することなく、同一版として扱う模型関係を複数の状態へ適用できることをいう。

一入力専用の固定応答そのものは、再利用可能な模型関係とは扱わない。

## 3. 言語模型

> **言語模型とは、宣言した言語関係を対象とし、その対象関係に対する有限かつ再利用可能な模型関係を持ち、定めた観測・判定条件のもとで両者の対応が確認される成立物である。**

言語を入口や出口に使うだけでは言語模型としない。

言語模型性の中心は、**言語関係が模型化の対象になっていること**である。

## 4. 最小

本規定における「最小」は、物理部品数・クラス数・ファイル数・責任名の数を最少にする意味ではない。

> **最小とは、ある成立を閉じるために必要な区別・関係・判定条件のうち、一つを外すと同じ成立を同じ意味で判定できなくなる局所境界である。**

したがって、責任数を2個・3個・5個に減らすこと自体を最小化としない。

### 最小性監査

最小性を主張する場合、少なくとも次を確認する。

1. その要素・関係を除く。
2. 残りだけで同じ対象・同じ関係・同じ判定を閉じられるかを見る。
3. 隠れた前提として別の場所へ移っただけでないか確認する。
4. 統合した場合、意味差・境界差・時間差が失われないか確認する。
5. 結論が分岐するなら最小化は未閉包として保留する。

## 5. 大規模

本規定における「大規模」は、特定のパラメータ数・データ量・計算量を意味しない。

> **大規模とは、同一の模型関係が扱える言語状態・言語関係・再利用範囲の広がりが、局所用途を越えて拡張されている程度を表す。**

現時点では少なくとも次を別々に記録する。

### 状態域の広がり

扱える言語状態、表現粒度、媒体、形式、語彙・構造の広さ。

### 関係域の広がり

扱える言語関係の種類、距離、階層、複雑さ、文脈依存の広さ。

### 再利用域の広がり

未列挙組合せ、異なる文脈、異なる話題・領域へ、同一模型関係をどこまで差替えなしで再利用できるか。

大規模性の一点普遍閾値は現時点で規定しない。

## 6. 機能

> **機能とは、対象・条件・境界を固定したとき、その成立物が何を成立させるかという結果側の責任である。**

言語模型の最小機能候補は、宣言した言語関係について、現在状態から対象関係に対応した区別・評価・復元・継続・変換等を形成できることである。

機能は実装方式と同一ではない。

## 7. 作用

> **作用とは、現在状態に対して模型関係が働き、次の状態差を生じさせる局所的な変化である。**

作用はAttention、FFN、rule、lookup等の部品名に固定しない。

言語模型実行系を観測する場合、少なくとも

```text
現在状態
→ 模型関係の作用
→ 結果状態
```

の関係を追跡する。

## 8. 境界

> **境界とは、何を同じ成立物へ含め、何を別の成立物・形成過程・運用条件として分けるかを定める局所規則である。**

最低限、次を区別する。

- 対象 / 模型
- 模型物 / 実行器
- 形成過程 / 実行過程
- 言語模型性 / 大規模性
- 模型 / 利用系
- 模型内部状態 / 外部観測結果

境界は普遍的な物理位置として固定せず、対象ごとに明示する。

## 9. 観測

> **観測とは、対象・条件・方法・時点を伴って得られた差分であり、対象本体そのものではない。**

観測方法・証拠密度・未観測範囲を保持する。

同じHDS語彙で構文化されたこと自体を、独立した実物証拠とは数えない。

## 10. 規定

> **規定とは、対象・関係・境界・同一性・判定・保留を、特定版内で再構成可能に固定する運用上の約束である。**

規定を対象世界の絶対法則へ昇格しない。

## 11. 版内固定と再開放

本書の語義は版内では固定する。
無言変更を禁止する。

ただし「言語」「模型」「最小」「大規模」「機能」「作用」「境界」「観測」「規定」という語自体も現時点の有限射影であり、新観測によって再開放できる。
