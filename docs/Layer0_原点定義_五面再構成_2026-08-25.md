# 言語模型最小成立規定 — 原点定義の五面再構成（仮）

状態: 草案 / 非正本 / 再開放可

## 0. 問題

旧Layer-0は「必要component」「機能責任」「実装写像」「適合試験」を一つの層へ集めたため、何がLLMの成立条件で、何が実装方式で、何が運用上の観測条件かが混線した。

新規定では、部品数を先に決めず、LLMを観測・定義する面を分ける。

## 1. 機能面 — 何を成立させるか

言語模型の機能面では、外部語としての「生成」「推論」「チャット」を先取りしない。

最低限問うのは、

> **宣言した言語対象関係について、入力・文脈・状態差に応じた区別、対応、評価、復元、継続、変換等を形成できるか。**

である。

機能面だけから内部方式を推測してはならない。

### 機能成立

内部構造が非公開でも、十分な入力差・文脈差・摂動に対し、宣言した言語対象関係に沿う結果差が反復して観測できる場合、**言語模型機能の成立**を局所的に認められる。

ただし、これを特定の内部模型構造の証拠へ昇格しない。

## 2. 模型面 — 何を有限に保持しているか

模型面では、対象言語関係と模型内部関係を分ける。

> **模型面とは、対象言語関係の一部を、版として同定可能な有限成立物の内部で、複数状態へ再利用できる関係として保持しているかを見る面である。**

模型物の形式は固定しない。

- 重み
- 規則
- 表
- グラフ
- 状態遷移
- プログラム
- 混成系

等を許容する。

### 模型構造確認

内部artifact・設定・code・weight・規則等を観測できる場合のみ、その範囲で模型構造を確認する。

閉鎖モデルについて、機能成立から内部Attention/MoE/状態形式等を逆算して確定してはならない。

## 3. 実行面 — 現在状態へどう作用するか

模型物と、それを入力へ適用する実行を分ける。

実行面の最小観測は、

```text
現在状態
→ 模型関係の作用
→ 結果状態
```

である。

現在状態・結果状態は文字列である必要はない。
ただし、宣言した言語対象関係への接続を観測境界で追跡可能でなければならない。

### 実行面に含み得るもの

- 状態更新
- 参照
- 比較
- 復元
- 選択
- 合成
- 反復

### 実行面へ自動的に含めないもの

- serving scheduler
- UI
- external tool
- safety classifier
- agent loop

ただし候補系の成立に不可欠なら、境界面で別成立物として接続を記録する。

## 4. 境界面 — どこまでを同じ成立物とするか

少なくとも次を分離して記録する。

1. 対象言語関係 / 模型内部関係
2. 模型物 / 実行器
3. 模型 / 入出力接続
4. 模型 / 外部知識
5. 模型 / 検索・tool・agent
6. 模型 / safety・approval
7. 模型 / 製品UI
8. 模型 / 形成過程

境界は全対象共通の物理位置へ固定しない。

### 閉鎖サービスの扱い

内部境界が確認できない場合、サービス全体を「言語模型本体」と断定しない。

- 言語模型機能: 観測可能
- 模型物境界: 未観測
- 実行器境界: 未観測
- 外部制御境界: 一部観測

のように分けて保留を残す。

## 5. 形成面 — どう作られたか

形成面は重要だが、言語模型性そのものとは分離する。

- 学習
- 後学習
- 手書き
- コンパイル
- 探索
- 蒸留
- 進化
- 人手編集
- 混成

等を記録する。

「学習済みだから言語模型」「手書きだから言語模型ではない」という判定を禁止する。

## 6. 五面の非対称性

五面は五つの物理componentではない。

- 機能面は結果側の成立。
- 模型面は有限な関係保持。
- 実行面は現在状態への作用。
- 境界面は含有・分離の規則。
- 形成面は時間的な生成経路。

同じ機構が複数面へ関与してよい。

## 7. 最小性の意味

最小化の対象は「五面を何個に減らせるか」ではない。

> **言語模型という判定を、対象・関係・境界・作用・観測の意味を失わず閉じるために、どの区別が不可欠か。**

を監査する。

部品数最小化と定義最小化を混同しない。

## 8. 現時点の成立候補

### 言語模型機能

宣言した言語対象関係について、状態差に応じた対応結果を反復して形成できる。

### 言語模型構造

宣言対象に対応する、有限かつ再利用可能な模型関係が確認される。

### 実行可能言語模型系

現在状態へ模型関係を適用し、対象関係へ接続可能な結果状態を形成する実行閉路が確認される。

これらを一語のPASSへ潰さない。

## 9. 現代LLMとの関係

Llama / OLMo / Qwen / DeepSeek / Kimi等は、機能面・模型面・実行面の実在証人として再観測する。

Dense、MoE、Attention、recurrent、compression、routing等の差は模型面・実行面の具体形であり、それ自体を普遍必須へ昇格しない。

OpenAI / Claude / Gemini等の閉鎖系は、機能面の観測と公開された境界面のみを証拠とし、内部模型面は未観測として残す。

## 10. MINIDORAの扱い

MINIDORAは旧Layer-0を基準に構成されたため、新規定の成立証人から除外する。

新規定が独立観測群で閉じるまで、

- MINIDORAがLLMか
- MINIDORAのどの部品が新Layer-0に対応するか
- MINIDORAをどう直すか

を確定しない。

新規定確定後、MINIDORAを五面すべてでゼロから再監査する。
