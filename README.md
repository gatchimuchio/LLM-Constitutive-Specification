# 大規模言語模型成立規定

> **状態:** 局所安定正本 / 再開放可  
> **版:** 2026-08-26-成立規定-2  
> **旧称:** Layer-0（歴史上の暫定名称。現行構造名ではない）

このリポジトリは、現在 Large Language Model / LLM と呼ばれている異種の実在系を横断観測し、**何が成立すれば大規模言語模型と扱えるか**を日本語を一次規定言語として定めます。

## 規定言語

日本語を表示言語ではなく、**定義・分別・判断・改訂の一次規定言語**とします。

他言語は外部API、標準規格、プログラム構文、固有名、原文引用、検索再現、国際公開など、実務上やむを得ない接続面だけで使用します。

## 対象とする「言語」

自然言語だけへ限定しません。

対象として明示した言語体系を扱います。自然言語、プログラム言語、その他の明示された言語体系を含み得ます。任意のラベル・ID・数値列を名称だけで言語へ昇格させません。

## 言語模型性の中核

```text
候補模型から独立して固定した対象言語関係
        ↕
      局所対応
        ↕
文脈付き内部状態から成立差を生じさせる模型側関係
```

この対応を読めるように、対象言語体系側と模型内部側を結ぶ **言語対応** を境界契約として保持します。

成立差は、未確定な言語状態について文脈に応じて生じる、成立可否・適合・優先・制約・選択等の差です。確率分布やscore等は実装例であり普遍形式ではありません。

## 局所対応の成立確認

候補模型の出力を見て基準を後付けしません。

成立確認の最低限の証拠は、

1. 差分追従
2. 複数対照への再利用
3. 再現性

です。

保存追従・破壊追従・各種摂動・benchmark等は強い補助証拠として使えますが、すべてのLLMへ一律の成立条件にはしません。

## 生成は別の性質

大規模言語模型成立に、外部文章生成を必須としません。

欠損復元、候補評価、変換先評価等でも、対象言語関係に局所対応する成立差を模型側が生じさせれば言語模型性を持ち得ます。

外部へ新しい言語状態を確定・更新・反復形成できる性質は **生成運用性** として別に記録します。

## 普遍必須へ置かないもの

- Transformer
- Attention
- MoE
- 自己回帰
- 左から右の生成
- 次token予測
- 確率分布
- softmax
- sampling
- KV cache
- 特定tokenizer
- 学習済みであること

## 大規模性

言語模型性と規模を分けます。

規模は、

- 状態域規模
- 関係域規模
- 共有適用規模

の三面で記述します。

「大規模」は対象範囲・版・時点・比較集合を明示した相対記述です。規模と汎用性・多領域性を同一視しません。

## 裏取り

現行版は、MINIDORAリポジトリ内のHDS横断観測資料と、Code Llama、BERT系masked language modeling、LLaDA、RWKV、BloombergGPT等の外部一次資料を再突合して修正・確認しています。

HDSは観測・分析方法として使用しています。この成立規定そのものはHDSを前提知識として要求しません。

MINIDORAおよびHDS Compilerを本規定に合わせて成立させる証人にはしていません。本版確定後に上流基準として一方向に適用します。

## 再開放

本規定は対象範囲・版・観測条件を明示した局所安定正本です。新しい射程内反例が現れた場合は必要な前提まで戻って再監査します。

## 監査

```bash
python scripts/規定監査.py
python -m unittest discover -s tests -p 'test_*.py'
```
