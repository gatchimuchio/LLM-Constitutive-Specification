# 大規模言語模型成立規定

> 状態: **凍結正本 / 射程内反例時のみ再開放**  
> 版: `2026-08-29-成立規定-9`

## 最上位理論と言語規定

本規定体系の最上位理論正本は [`cognitive-engineering-foundations`](https://github.com/gatchimuchio/cognitive-engineering-foundations) とする。

- 参照commit: `60131da52ba7931ed7f82c7648a74ac790f50d08`
- 基底言語・規定言語: **日本語**
- 他言語: 実務上必要な外部接続に限って例外使用

```text
日本語で対象化・差異化・関係化
→ 日本語で定義・構造化
→ 日本語で監査・改訂
→ 日本語正本成立
→ 実務上必要な場合だけ他言語へ射影
```

## v9で固定したもの

v8で確定した厳密言語模型中核、模型境界、能力作用構成、日本語基底、循環再帰は維持する。

```text
完全言語状態空間
+ 持続模型状態
→ 一つの整合した言語確率法則
```

v9では、**能力作用構成の観測と、それらを統合して判断を成立させる意思決定構造を分離**した。

```text
観測可能な局所作用群
≠ それらを成立させる全体系

局所作用再現
≠ 作用関係再現
≠ 意思決定構造再現
≠ 能力主体
```

状態保持、後続利用、参照変更、経路変更、再参照、再結合等を観測・再現できても、それだけで「何を目的とし、何を対象とし、どの状態を採用し、何を棄却し、どこまで進行するか」を決める構造まで得られたとはしない。

## MINIDORAとHDSの境界

MINIDORAでは、LLM構成側だけでは能力主体として閉じず、**HDSが別の判断主体として必要**である。

HDSは、MINIDORAにおいて目的・対象・文脈・状態を関係づけ、採否・進行・権限等の判断を担う。

ただし、ここから次を導かない。

- HDSをLLM一般の普遍成立条件としない。
- HDSを既存LLM群の構成観測から抽出できるとはしない。
- HDSの内部原理・定義・実装を本構成定義へ取り込まない。
- MINIDORAでHDSが必要であることと、厳密言語模型成立を同一視しない。

本リポジトリが固定するのは、**構成定義から意思決定原理・能力主体までを自動導出できないという射程境界**である。

詳細は [`規定/08_構成定義の到達限界.md`](規定/08_構成定義の到達限界.md) を正本とする。

## 能力作用構成

`規定/07_能力作用構成.md` では、少なくとも次を別観測とする。

```text
状態担体
作用
状態差
後続利用
参照変更
経路変更
計算量変更
再参照
再結合
循環尺度
```

これは厳密言語模型成立条件でも、HDSの定義でもない。

## 境界

```text
言語模型物
≠ 言語模型実行系
≠ 利用系

厳密言語模型
≠ 条件付き言語模型
≠ 局所言語予測
≠ 言語得点関係
≠ 言語表現模型
≠ 言語変換模型
```

## 再現

```text
機能再現
能力再現
構造再現
因果機構再現
```

に加え、v9では次の非同一性を固定する。

```text
局所作用再現
≠ 作用関係再現
≠ 意思決定構造再現
≠ 能力主体
```

## 凍結

本版を構成定義正本として凍結する。

凍結後、次だけでは再開放しない。

- MINIDORAの性能向上・低下
- HDSの改定
- HDS実装方式の変更
- 現行観測単位で記述可能な追加LLMの観測
- 個別実装の都合

再開放するのは、**本規定の射程内で、現行の言語模型成立・境界・観測単位・分別自体を破る具体的反例または新観測が得られた場合**に限る。

履歴は削除せず、v1〜v8を成立過程として保存する。
