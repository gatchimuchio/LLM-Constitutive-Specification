# 大規模言語模型成立規定

> **状態:** 局所安定正本 / 再開放可  
> **版:** 2026-08-28-成立規定-4  
> **旧称:** Layer-0（歴史上の暫定名称。現行構造名ではない）

このリポジトリは、現在 Large Language Model / LLM と呼ばれている異種の実在系を横断観測し、**何が成立すれば大規模言語模型と扱えるか**を日本語を一次規定言語として定めます。

## 規定言語

日本語を表示言語ではなく、**定義・分別・判断・改訂の一次規定言語**とします。他言語は外部API、標準規格、プログラム構文、固有名、原文引用、検索再現、国際公開など、実務上やむを得ない接続面だけで使用します。

## 対象とする「言語」

自然言語だけへ限定しません。自然言語、プログラム言語、その他の明示された言語体系を対象にできます。任意のラベル・ID・数値列を名称だけで言語へ昇格させません。

## 言語模型性の中核

```text
候補模型から独立して固定した対象言語関係
        ↕
      局所対応
        ↕
文脈付き内部状態から成立差を生じさせる模型側関係
```

言語模型性の最小成立条件は、**独立対象 / 文脈依存関係 / 関係再利用 / 言語対応 / 局所対応**の五区別です。内部構造を直接観測できない閉鎖模型にも適用できる意味上の最小条件として維持します。

## 構成再現条件

実在LLMの内部作用を観測・構文化し、別模型へ忠実に再構成する場合は、最小成立条件とは別に次を保存対象とします。

1. 状態分離・保持・更新
2. 意味・関係同一性追跡
3. 未確定差の共存
4. 寄与調整と確定分離
5. 構成連鎖 / 再作用・再結合
6. 再作用閉包 / 終端成立差
7. 形成済み関係の保持 / 作用機構との分離

**LLMとして成立するか**と、**特定LLMの能力成立構成を忠実に再現できているか**を同一視しません。

## v4で締めた構成再現の境界

v3の七区別は維持しつつ、同じ語を別物へ縮退させないため、次を明示しました。

- **作用状態 != 評価メタデータ** — 得点・順位・寄与値・ログだけの変化を状態遷移へ昇格しない。
- **状態更新 = 実効的な状態遷移** — 前段作用で生じた差が、後段作用の入力・適用条件・利用可能性・制約・終端の少なくとも一つを変える。
- **再作用 != 再採点** — 同一状態へ同じ評価器を再適用するだけでは再作用成立としない。
- **checkpoint保持 != 実効再利用** — 保存・件数増加だけでなく、後段が読み出し、その内容差によって作用が変わることを要求する。
- **再結合 != 最終得点の単純合算** — 複数差の結合結果が後続作用の新しい状態・条件・制約または成立差へ接続することを要求する。
- **端到端構成再現 != fixture後段適合** — 宣言した入力 / Data境界から必要な中間状態・作用条件が内生形成されることを要求する。

## v4改定理由

下流MINIDORAの構成再現v3では、component / unit testが全面通過しても、実入力では保持した中間状態の実効再利用・候補横断更新・再作用が発火しないケースが観測されました。

これは下流点数そのものを根拠に規定を変更したものではありません。v3の独立LLM横断構文化には既に「状態保持→更新→再作用→再結合」「途中差を後段へ渡す」という作用が抽出されていましたが、規定から実装へ降ろす際に、`状態` が候補得点、`再作用` が再評価、`再結合` が寄与合算へ縮退しても形式上適合できる余白が残っていました。

v4は新しい物理部品を要求せず、**v3で既に採用した作用語の成立条件と非成立条件を精密化した版**です。

## 局所対応の成立確認

成立確認の最低限の証拠は **差分追従 / 複数対照への再利用 / 再現性** です。保存追従・破壊追従・各種摂動・benchmark等は補助証拠であり、すべてのLLMへ一律の成立条件にはしません。

## 生成は別の性質

大規模言語模型成立に外部文章生成を必須としません。外部へ新しい言語状態を確定・更新・反復形成できる性質は **生成運用性** として別に記録します。

## 普遍必須へ置かないもの

Transformer、Attention、MoE、自己回帰、次token予測、確率分布、softmax、sampling、KV cache、特定tokenizer、特定層数、特定checkpoint周期、学習済みであること等を普遍条件へ固定しません。

## 大規模性

言語模型性と規模を分けます。規模は **状態域規模 / 関係域規模 / 共有適用規模** の三面で記述します。作用範囲・段階輸送・未確定差共存等は必要に応じて三面の補助記述へ入れ、第四の規模面を無根拠に増設しません。

## 循環禁止

```text
実在LLM群の独立観測・既存構文化
→ 大規模言語模型成立規定
→ 下流再構成
→ 下流逆算監査
→ 既存独立構文化との一致確認
→ 必要箇所のみ正本再開放
```

MINIDORAおよびHDS Compilerを本規定に合わせて成立させる証人にはしません。
