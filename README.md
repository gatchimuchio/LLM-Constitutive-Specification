# 大規模言語模型成立規定

> 状態: 局所安定正本 / 再開放可  
> 版: `2026-08-28-成立規定-8`

## 最上位理論と言語規定

本規定体系の最上位理論正本は [`cognitive-engineering-foundations`](https://github.com/gatchimuchio/cognitive-engineering-foundations) とする。

- 参照commit: `60131da52ba7931ed7f82c7648a74ac790f50d08`
- 基底言語・規定言語: **日本語**
- 他言語: 実務上必要な外部接続に限って例外使用

```text
日本語で対象化・差異化・関係化
→ 日本語で定義・構造化
→ 日本語で監査・改訂
→ 日本語正本成立
→ 実務上必要な場合だけ他言語へ射影
```

`LLM`、`n-gram`、BERT等は外部慣用名・固有名・方式名として保持できるが、正本概念は日本語で定義する。

## v8の中核

v7で確定した厳密言語模型中核は維持する。

```text
完全言語状態空間
+ 持続模型状態
→ 一つの整合した言語確率法則
```

局所条件確率や生成遷移は、完全言語状態上の法則へ接続されることで成立形になる。

v8ではこの関係を **局所条件から完全法則への接続** と呼ぶ。

## v8の主要修正

- 日本語規定を全正本・索引・監査器へ貫通させた。
- `scorer` 等の外部語を日本語正本概念へ置換し、必要時だけ外部対照名として残した。
- `言語得点関係` と厳密言語模型を分離した。
- 能力を最終得点だけで扱わず、`能力作用構成` を独立正本化した。
- 状態の存在、後続利用、参照変更、経路変更、再参照、再結合、循環尺度を分離した。
- 固定された「再開放順序」を廃止し、必要な座標を同時に開ける循環再帰へ変更した。

## 能力作用構成

`規定/07_能力作用構成.md` では、少なくとも次を別観測とする。

```text
状態担体
作用
状態差
後続利用
参照変更
経路変更
計算量変更
再参照
再結合
循環尺度
```

特に、

```text
状態が存在する
≠ 状態が後続利用される

後続利用される
≠ 参照が変わる
≠ 経路が変わる
```

を固定する。

これは厳密言語模型成立条件ではない。

## 境界

```text
言語模型物
≠ 言語模型実行系
≠ 利用系

厳密言語模型
≠ 条件付き言語模型
≠ 局所言語予測
≠ 言語得点関係
≠ 言語表現模型
≠ 言語変換模型
```

## 再現

```text
機能再現
能力再現
構造再現
因果機構再現
```

を分ける。

## MINIDORA

MINIDORAのGPQA等は能力監査である。

厳密言語模型性は、参照ニューラル模型の構造をコピーしたかではなく、完全言語状態上の整合した言語確率法則を成立させるかで監査する。

一方、MINIDORAの実測は能力作用構成・観測方法・構成定義を再開放する独立観測として利用できる。

## 循環再帰

```text
構成定義
↕
構文化
↕
実装
↕
実測
↕
観測方法・前提
```

責任範囲は分けるが、一方向の固定上流下流とは扱わない。
