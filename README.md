# 大規模言語模型成立規定

> **状態:** 局所安定正本 / 再開放可  
> **版:** 2026-08-28-成立規定-5  
> **旧称:** Layer-0（歴史上の暫定名称）

このリポジトリは、異種の実在 Language Model / LLM を横断し、**模型そのものの成立条件、成立を確認する監査条件、機能再現、構成再現、大規模性、運用境界**を日本語で分離して規定します。

## v5の核心修正

v4まで維持していた「言語模型性五条件」「構成再現七条件」「規模三面」を前提から外しました。

理由は次です。

- `独立対象 / 言語対応 / 局所対応` は模型内部の成立条件ではなく監査条件だった。
- 高能力LLMで観測した状態保持・再作用等を、全模型の普遍構成再現条件へ昇格していた。
- `形成済み関係` を学習済み模型状態一般へ広げ、未観測の意味構造を実体化する余地があった。
- retrieval等を部品種別で模型外へ寄せると、REALM / RETRO型の統合模型を誤分類し得る。
- `大規模` の固定三面は有用な観測軸だが、実在LLMのscale用法を完全には表さない。

## 言語模型性の四条件

現行版では模型内在条件を次へ整理します。

1. **言語状態域**
2. **条件付き言語差形成**
3. **構成再利用**
4. **言語状態接続**

```text
言語状態域
+ 条件付き言語差形成
+ 構成再利用
+ 言語状態接続
= 言語模型性
```

Transformer、Attention、RNN、自己回帰、拡散、MoE、確率分布、sampling、学習済みであることを普遍必須にしません。

## 識別監査は別

言語模型性を外部から確認するため、次を使います。

- 独立対象固定
- 言語対応
- 差分追従
- 複数対照への再利用
- 未列挙構成監査
- 再現性

これらを模型部品として数えません。

## 機能再現と構成再現

**機能再現**は、入力・文脈差から言語状態域上の成立差を再現することです。内部構造一致を要求しません。

**構成再現**は、元模型について観測され、対象能力へ因果的に関与する構成不変量を、元模型相対の再現対象プロファイルに従って再現することです。

```text
機能再現 != 構成再現
```

非ニューラル代替模型が既存Transformer等の内部構造をコピーしないこと自体は、機能再現の失敗ではありません。

## 旧七条件の扱い

状態保持、未確定差共存、寄与調整、再作用・再結合、終端遅延等は、高能力LLM比較に有力な**構成観測軸**として残します。

ただし全模型の構成再現へ同一に要求しません。

## 模型境界

retrieval、memory、router、adapter、tool等を部品名だけで模型内外へ分類しません。

模型同一性、実行必須性、形成結合、介入影響、展開任意性から判定します。

## 大規模性

`large` は言語模型性とは別の相対記述です。固定三面・単一parameter閾値を普遍化せず、比較集合と尺度を明示した**規模プロファイル**で記録します。

## 循環禁止

```text
実在模型・一次資料
→ 構造候補
→ 反例監査
→ 規定
→ 下流実装
→ 下流失敗を反例として上位まで再開放
```

下流実装を上位規定の成立証人にはしません。
