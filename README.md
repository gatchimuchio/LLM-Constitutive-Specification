# 言語模型成立規定

> **状態:** 局所安定正本 / 再開放可  
> **版:** 2026-08-25-成立規定-1  
> **旧称:** Layer-0（歴史上の暫定名称。現行構造名ではない）

このリポジトリは、現在「大規模言語モデル（LLM）」等と呼ばれている実在系を横断観測し、**言語模型とは何か、何が成立すれば言語模型と扱えるか、規模・生成運用・形成履歴・利用外周をどこで分けるか**を、日本語を一次規定言語として規定します。

## 規定言語

日本語を表示言語ではなく、**定義・分別・判断・改訂の一次規定言語**とします。

他言語は、外部API、標準規格、プログラム構文、固有名、原文引用、検索再現、国際公開など、実務上やむを得ない接続面だけで使用します。他言語の一般語義から日本語正本の意味を逆定義しません。

## 言語模型成立の中核

現行版の最小閉包は次です。

```text
候補模型から独立して固定した対象言語関係
        ↕
      局所対応
        ↕
文脈付き内部状態から成立差を生じさせる模型側関係
```

この対応を読めるように、対象自然言語側と模型内部側を結ぶ **言語対応** を境界契約として保持します。

ここでいう成立差は、未確定な自然言語状態について文脈に応じて生じる、成立可否・適合・優先・制約・選択等の差です。確率分布やscore等は実装例であり普遍形式ではありません。

## 局所対応の監査

候補模型の出力を見て基準を後付けしません。対象言語関係を先に固定し、少なくとも次を監査します。

1. 差分追従
2. 保存追従
3. 破壊追従
4. 複数対照への再利用
5. 再現性

これらが対象範囲・版・観測条件で閉じ、重大な射程内反例が残らない場合に局所安定とします。

## 生成は別の性質

言語模型成立に、外部文章生成を必須としません。

欠損位置の候補適合、変換先評価、文脈に対する言語状態評価等でも、対象言語関係に対応する成立差を模型側が生じさせれば言語模型になり得ます。

外部へ新しい自然言語状態を確定・更新・反復形成できる性質は **生成運用性** として別に記録します。

## 普遍必須へ置かないもの

現行版では、次を言語模型成立の普遍必須条件にしません。

- Transformer
- Attention
- MoE
- 自己回帰
- 左から右の生成
- 次token予測
- 確率分布
- softmax
- sampling
- KV cache
- 特定tokenizer
- 学習済みであること

## 規模は別に記述する

言語模型成立と規模を分けます。

規模は、

- 状態域規模
- 関係域規模
- 共有適用規模

の三面で記述します。

「大規模」は普遍的一点閾値ではなく、対象範囲・版・時点・比較集合を明示した相対記述です。規模と汎用性・多領域性を同一視しません。

## 参照集合と成立証拠を分ける

Llama 3、K2-V2、OLMo 3、Apertus 1.5、Qwen3.6、DeepSeek V4、Kimi K3、LLaDA-8B等を横断観測の参照集合に置きます。

提供者や業界がLLMと呼んでいること自体は成立証拠にはしません。各候補へ名称から独立して本規定を適用します。

MINIDORAおよびHDS Compilerは旧規定から派生した下流物であるため、この規定の成立証人には使用していません。本版の局所安定化後に、上流基準として一方向に適用します。

## 再開放

本規定は対象世界の絶対法則を宣言するものではありません。対象範囲・版・観測条件を明示し、未観測・未確定・矛盾・再開放を保持します。

新しい射程内反例等が現れた場合、局所項目だけを帳尻合わせせず、必要な前提まで戻って再監査します。

```bash
python scripts/規定監査.py

```
